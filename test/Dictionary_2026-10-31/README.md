# 내 사전과 교정 후보 검증

`swift test` 전체 463개 테스트가 2026-10-31 통과했다. `PersonalDictionaryTests`의 12개 테스트는 임시 저장소와 합성 문장으로 실행하며 실제 사용자 사전을 변경하지 않는다.

- 현재 작품 기본값과 명시적 저장, 전체/여러 작품 공유, 동명이작 격리
- 재로드, 비활성 항목 재등록, 변경 전 백업, 손상 및 저장 실패 시 원본 보존
- 폴더 이동과 문서 경로 변경 시 적용 범위 갱신
- 등록 표현만 제외하고 인접 오류 보존, Kiwi 재호출 없이 캐시 재필터
- 스크롤/페이지 보기의 포커스·호버 팝오버, 해당 후보 적용과 서식을 포함한 Undo
- 선택 검사 시트에도 동일한 필터 적용과 등록 직후 갱신

검토 앱: `.build/JenaNote-Dictionary-review.app`. 실제 문장에서 Kiwi의 모든 오탐·누락이 해결된다는 의미는 아니다.
