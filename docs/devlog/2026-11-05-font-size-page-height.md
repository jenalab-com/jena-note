# 실제 글자 크기와 세로 화면 맞춤

문서의 실제 본문 글자 크기를 헤더의 본문 옆에서 pt로 정한다. 직접 입력하거나 1pt씩 움직이며 범위는 8~30pt다. 보기 설정에는 이전처럼 글자 작게/크게 버튼을 두고 화면 배율을 %로 보여준다. 둘은 따로 저장되고 화면에는 실제 크기 × 화면 배율로 그린다. 제목과 코드 글자도 같은 비율로 따라온다.

DOCX·HWPX 내보내기도 실제 글자 크기를 쓴다. 이전에는 HWPX 본문이 10pt로 고정이고 DOCX 본문은 크기를 지정하지 않았으며 제목도 고정 크기라, 본문을 키우면 제목이 더 작아졌다. 제목과 코드는 `ExportTypography`로 앱과 같은 비율을 쓴다. 크기를 건드리지 않으면 내보낸 본문은 기본값 15pt가 된다.

문서 크기는 가로 폭만 정한다. 치수자와 문서 크기는 가로를 맞춰 보려는 기능이고 인쇄는 내보내기로 하므로, 페이지 높이는 용지 높이 대신 화면 높이를 따른다. 큰 화면에서 A4 높이에 묶여 글이 중간에 끊겨 보이던 문제가 없어진다. 대신 창 높이를 바꾸면 쪽 나눔이 달라진다.

자간은 보기 설정에서 %로 정한다. 범위는 -10~+20%이고 기본은 0%다. 원고 파일에는 저장하지 않고 조판 단계에서 얹으며, DOCX는 글자 크기별 1/20 pt로, HWPX는 %로 내보낸다. 코드는 고정폭이라 자간을 넣지 않는다. 화면 배율 기본값은 130%로 했다.
