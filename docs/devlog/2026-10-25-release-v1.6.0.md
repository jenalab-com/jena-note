# v1.6.0 릴리스

## 변경
- Makefile과 Info.plist의 두 버전 값을 1.5.0에서 1.6.0으로 동기화했다.
- 통합 페이지 편집, 증분 페이지 계산, 원문 보기, CLI AI 대화/설정/모델/사용량/Markdown 표시를 포함한다.
- 사이드바 새 문서·폴더 생성, 우클릭 파일 관리, 더블 클릭 이름 변경과 Jena 제품군 아이콘을 포함한다.
- 상세 구현은 같은 날짜의 기능별 개발 로그에 기록했다.
