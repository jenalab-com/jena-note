# 배경색·백업·문서 끝 주석 구현

## 요청과 결정
`docs/research.md` 검토 후 사용자가 배경색, 백업, 주석을 먼저 요청했다. 설계/기획 로그/ADR-0018을 먼저 작성하고 구현했다. 원고 원본과 보기 설정을 분리하고, 복원 안전을 우선한다.

## 변경
- PaperBackground: 기본/세피아/연녹색/회색 및 라이트/다크 대응. UserDefaults 전역 선택, 설정 창에 항목 추가, 스크롤/페이지/소스 보기 갱신. 문서 서식에는 배경을 넣지 않음.
- DocumentBackupStore: 문서 경로 해시별 Application Support JSON 스냅샷, 원자 저장, 동일 내용 중복 제거, 자동 저장 5분 간격·수동 저장 즉시, 최근 100개 보관. 마지막 백업 캐시로 매 자동 저장 때 전체 이력을 읽지 않음.
- NSDocument.writeSafely 경계에서 첫 덮어쓰기 전 디스크 원본과 저장 성공본을 백업. 낮은 수준 write(to:…originalContentsURL:)는 임시 경로일 수 있으므로 실제 목적지를 받는 안전 저장 경계를 사용. [Apple NSDocument 문서](https://developer.apple.com/documentation/appkit/nsdocument/).
- 파일 메뉴 백업 목록·미리보기·복원. 복원 직전 미저장 내용 백업 성공이 필수, 기존 문서 Undo 경계 사용. 백업 오류는 알리되 원고 저장은 완료함.
- DocumentEndnotes: 본문 번호와 끝 설명, Markdown 참조/정의 왕복, 안정 ID, 삽입/수정/삭제/이동. 단일 설명 문단. 코드 안 참조 표기는 해석하지 않음. docx/hwpx는 표시 텍스트 보존.

## 검증 중 발견/수정
- NSColor 동적 색 객체의 식별자 대신 해석된 색을 비교하도록 테스트 수정.
- 기존 Markdown 파서의 끝 개행 표현은 저장 직렬화 기준으로 비교해 원고 보존을 검증.
- 복원 테스트가 임시 파일을 지운 뒤 NSDocument 자동 저장 오류 창을 띄워 회귀 실행이 대기했다. 테스트용 문서에서는 자동 저장 타이머를 끄고 안전 저장 메서드를 명시 호출하도록 분리했다. 테스트 문서는 변경 없음 처리·닫은 뒤 임시 폴더를 정리한다. 앱의 저장 오류를 숨기는 처리는 하지 않음.
- 자기 자신을 참조하는 주석 삭제 시 정의와 참조의 중첩 범위를 중복 삭제하지 않도록 보완.

## 범위와 제한
텍스트 백업은 로컬 Mac/문서 경로별이며 이미지 파일·프로젝트 전체를 백업하지 않는다. 페이지 하단 각주, 복잡한 다중 문단 Markdown 각주, Word/HWP 전용 각주 객체는 포함하지 않는다. 버전 변경/설치 앱 교체/커밋/푸시/릴리스는 이번 요청 범위에 없음.
