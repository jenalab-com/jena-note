# 읽기·수정 모드와 툴바 통합

## 변경과 이유
사용자 요청에 따라 읽기/수정 모드 전환과 관련 버튼·메뉴를 제거했다. 문서는 처음 열 때부터 기존 읽기 조판을 적용한 편집 화면에 표시한다. 저장된 페이지/스크롤 보기 선택은 유지한다.

기존 수정 툴바의 서식·삽입·색상·검색 기능을 통합 툴바로 옮겼다. 본문/H1/H2/H3, 목록/번호 목록/인용, 링크/이미지/구분선은 메뉴로 묶어 좁은 창에서도 접근할 수 있도록 했다. 서체·화면 굵기·본문 폭·줄 간격·화면 배율은 보기 설정 팝오버에 모았다. 중복 줄 간격과 AI 버튼을 합쳤고 책갈피는 한 곳에 유지한다.

## 구현 결정
- 서식 명령은 원본 문단의 임시 텍스트 뷰에서 실행한 뒤 변경된 문단을 문서의 Undo 경로에 전달한다. 화면용 굵기와 배율이 저장되는 서식으로 섞이지 않는다.
- 페이지의 키보드 서식 명령도 동일한 편집 액션에 연결한다. 문서가 바뀌면 현재 화면과 대화가 새 문서를 따른다.
- 페이지에서 서식을 적용해도 스크롤로 전환하지 않는다. 기존 점진적 페이지 계산을 사용한다.
- 위치 복원·책갈피는 모드 진입 없이 동작한다. 창 종료와 문서 교체 시 현재 위치를 저장한다.
- AI 활성화 시 스크롤 표시와 종료 시 페이지 설정 복원은 유지한다.
- 페이지 찾기는 검색어 입력 시 다음 일치 항목을 찾아 선택하고, 스크롤 찾기는 기존 찾기 바를 사용한다.

## 검증
전체 테스트 216개 통과. 기존 모드 전환 테스트는 페이지/스크롤 전환을 검증하도록 변경했다. 새 통합 화면 테스트는 최초 편집 가능 상태, 모드 버튼 제거·중복 통합, 원본 서식 보존, 페이지 서식 적용과 Undo·Redo, 키보드 명령 전달, 문서 전환과 AI 선택 영역 전달을 검증한다. 기존 페이지 타이핑 성능 검사도 통과했다.

마지막으로 커서가 문서 맨 앞에 있을 때에도 화면 굵기 대신 원본 서식으로 굵게 버튼 상태를 표시하도록 보완했고, 통합 화면 테스트 4개를 다시 통과했다.

최종 릴리스 빌드 및 서명·Info.plist 검증 완료: `.build/unified-editor-preview-JmQuqD/JenaNote.app`.
