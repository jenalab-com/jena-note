# 본문 영역에서 원문으로 전환

## 변경
사용자 요청에 따라 원문 보기를 별도 창 대신 현재 문서의 본문 영역에 표시한다. 기존 원문 창 구현을 뷰 컨트롤러로 옮겨 복사·찾기·미저장 내용 표시와 읽기 전용 성격을 유지한다. 툴바 원문 보기 버튼을 다시 누르면 이전 페이지 또는 스크롤 편집 화면으로 돌아온다.

전환 전에 읽던 위치와 선택 범위를 보관하고 기존 페이지 편집기를 유지한다. 원문 표시만으로 문서 내용이나 Undo 이력, 페이지 보기 설정을 변경하지 않는다. 원문 상태에서는 문서 서식·보기 설정·책갈피 조작을 비활성화해 숨겨진 편집기에 명령이 적용되지 않도록 한다. 찾기는 원문 텍스트를 대상으로 한다.

## 문서와 AI 연결
파일이 바뀌어도 원문 표시는 유지하며 새 문서의 내용으로 갱신한다. 검색 결과 점프처럼 본문 선택이 필요한 동작은 편집 화면으로 돌아간다. AI 버튼으로 채팅을 열거나 닫으면 원문 표시를 종료한 뒤 기존 스크롤 전환 규칙을 적용한다. 채팅 중 원문을 표시할 수 있으며, 원문의 문자 오프셋을 문서 편집 좌표로 넘기지 않는다. AI·Undo가 문서를 바꾸면 원문을 갱신한다.

## 보존과 검증
작업 전 기존 편집기·툴바·원문 테스트·번역 파일을 임시 백업했다. 별도 창 검증을 본문 뷰 검증으로 변경하고, 페이지/스크롤 왕복, 동일 창 내 표시, 읽기 전용과 문서 불변, 파일 교체, AI 전환과 선택 좌표 분리를 테스트한다.

전체 테스트 222개 통과. 기존 원문 테스트의 독립 창 크기를 뷰 부착 후 명시하도록 수정했고, 실제 분할 본문에서도 원문 영역 너비를 검사했다. 숨겨진 원문 뷰는 문서 전환 시 불필요하게 직렬화하지 않도록 했다.

마지막 갱신 조건 변경 후 원문 테스트 6개 재통과. 릴리스 빌드와 서명·Info.plist 검증 완료: `.build/inline-source-preview-vJDhs2/JenaNote.app`.
