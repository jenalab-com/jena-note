# 작성화면 치수자와 좌·우 여백

- 요청: 작성화면 상단에 워드처럼 치수자를 넣고 좌·우 간격을 설정할 수 있게 한다. 2페이지(펼침면)면 페이지마다 치수자를 둔다.
- `PageRulerView` 신설: cm 눈금(0 = 글 시작점), 여백 핸들 끌기(0.25cm 격자, 글 영역 최소 120pt, 반대쪽 여백 불가침), 끄는 동안 cm 값 표시. 값은 저장하지 않고 놓을 때 `onMarginsCommitted` 로 한 번 알린다.
- `ReaderMetrics`: `pointsPerCentimeter`·`snappedMargin`·`clampedMargins`·`textWidth`·`storedMargins`. 여백은 페이지 폭을 바꾸지 않고 글 영역만 줄인다(ADR-0013).
- `ReaderViewController`: 페이지 컨테이너 크기를 `textBoxSize()`(페이지 폭 − 여백)로, 재분할 판정도 이 크기로. 페이지 뷰는 페이지 x + 좌 여백에 놓고 `layoutRulers` 가 페이지마다 치수자를 얹는다. 펼침면의 두 치수자는 같은 여백을 보여주고 함께 움직인다. `setPageMargins` 가 영속 + 재조판.
- `EditorViewController`(스크롤 보기): 단 폭 = 페이지 폭 − 여백, 치수자는 스크롤 뷰에 고정. 조판이 꺼지면 숨긴다.
- `SettingsManager.readingPageMarginLeft/Right` 추가(전역, 기본 0 — 기존 화면과 동일).
- 테스트 `PageRulerTests` 8개 신설, 전체 240개 통과. 릴리스 빌드 후 실제 앱에서 합성 마우스 이벤트로 왼쪽 핸들을 2.25cm 끌어 펼침면 양쪽 재조판·설정 저장·0 복귀를 확인했다.
- 미검증: 다크/라이트 모드 치수자 색 대비 육안(다크만 확인), 트랙패드 실손 끌기 감각, 매우 좁은 창(모바일 폭 + 큰 여백)에서의 안전망 UI.
- 두지 않은 것: 치수자 숨기기 토글, 문서별 여백, 들여쓰기 마커(워드의 첫 줄/왼쪽 들여쓰기).

## 같은 날 보완 — 핸들 잡기·페이지 넓히기

- 피드백: 양옆 핸들이 잘 안 잡힌다. 현재 폭에서 더 넓히고 싶다. 19cm가 A4 정도인가.
- 핸들 삼각형 8→12pt, 잡히는 범위 ±6→±12pt, `acceptsFirstMouse` 로 비활성 창에서도 첫 클릭에 잡히게 했다(전에는 첫 클릭이 창 활성화에만 쓰여 "안 잡힌다"고 느껴졌다).
- 페이지 폭은 글자수 설정(`readingLineLength`)에서만 나왔고 그걸 바꾸는 UI가 없어 사실상 넓힐 수 없었다. 여백 0인 핸들을 바깥으로 끌면 페이지가 넓어지도록 했다 — 끄는 동안 치수자 프레임이 그 방향으로 늘고, 놓을 때 `onCommitted(폭, 좌, 우)` 로 커밋. `SettingsManager.readingPageWidth`(0=자동)가 "책" 폭을 대체한다. 모바일은 고정. 상한은 창 폭(펼침면은 두 장 유지 폭).
- 더블클릭으로 폭·여백 초기화(`onReset`). 넓힌 뒤 되돌릴 길.
- A4: 종이 폭 21cm, 워드 기본 여백 2.5cm 제하면 본문 16cm. 19cm 페이지는 A4 본문보다 넓고 종이보다 좁다. 화면 cm는 72pt=1in 환산이라 실제 자와는 모니터마다 다르다.
- 테스트 10개(+2), 전체 242 통과. 릴리스 빌드 갱신.
