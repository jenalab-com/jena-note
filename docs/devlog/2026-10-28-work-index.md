# 작품 자동 인덱싱과 AI 자료 탐색

## 변경 이유
실사용에서 설정집·지난 화를 500KB에 맞추는 수동 작업이 집필 흐름을 끊었다. 작가는 자료 범위를 정하고, 앱은 작품을 지속적으로 정리하며, AI는 요청에 필요한 원문을 찾도록 바꿨다.

## 문서 선행
설계: `../superpowers/specs/2026-10-28-work-index-design.md`
구현 계획: `../superpowers/plans/2026-10-28-work-index.md`
ADR-0015와 기능 명세의 AC-16을 현행화했다. ADR-0014는 이력으로 유지한다.

## 구현
- `AIWorkIndex`: 원문을 최대 12,000 UTF-8바이트 조각으로 분할, 줄 범위·내용 해시·검색용 요약·파일 종류 보관. 단일 긴 줄도 UTF-8을 깨지 않고 분할한다.
- `AIWorkIndexStore`: 작품별 공유 큐, 백그라운드 스캔, 변경 조각만 요약, 원자 저장, 중단 후 재개, 동시 요청 병합. 동일 내용 조각은 요약을 재사용한다. 자료 등록·문서 열기·저장으로 자동 준비하며 저장 변경은 0.8초 모은다.
- `AIWorkRetrieval`: AI가 JSON으로 검색어/조각 ID/목차 페이지를 선택한다. 앱이 등록 자료·현재 화 이전만 검색한다. 4회·240초·근거 160KB 상한. CLI의 셸·도구 차단은 유지한다.
- `AIChatViewController`: 준비 완료 → 현재 본문 스냅샷 → 탐색 → 기존 가이드/수정. 대기/탐색 취소 시 질문 보존, 문서 전환과 수정 충돌 보호 유지. 검색과 답변 사용량은 채팅에, 작품 준비 사용량은 작품별 캐시에 집계한다.
- 상태바와 패널에 준비 상태 표시. 참고 자료의 용량 막대·수동 원문/요약 스위치를 감추고 등록·제외 범위만 관리한다. 지난 화 탭을 자동 준비·재시도·중지·요약 확인으로 교체한다.
- 기존 수동 요약 파일은 삭제하지 않는다. 이전 포맷의 호환 코드/회귀 테스트를 유지하며, 자동 인덱스는 원문으로 새로 만든다.

## 검증
- `swift test`: 전체 383개. 신규 인덱스/프로세스 통합 테스트 11개를 포함한다.
- 캐시 재로드 시 AI 호출 0회, 수정 파일만 재생성, 삭제 반영, 실패 후 재개, 동시 준비 중복 방지, 취소 후 늦은 응답 거부, 큰 한국어 파일의 무손실 분할, 미래 화/심볼릭 링크/제외 자료 차단.
- 실제 `AIClient`→`AIProcess`→테스트용 CLI 실행 파일을 거쳐 자동 준비→검색/읽기→답변을 검증. 미저장 본문 전달, 미래 정보 제외, 가이드 원문 보존, 준비/채팅 사용량 집계 확인. 외부 유료 AI는 호출하지 않았다.
- `make build`: release 빌드 및 `.build/JenaNote.app` 생성.
- 참고 자료/지난 화 탭의 AppKit 레이아웃 스냅샷을 생성해 배치·줄바꿈 확인. 캐시 렌더링은 일부 네이티브 버튼 외관을 재현하지 못하므로 실제 화면의 테마·색상 검증 완료로 간주하지 않는다.
- 실행 로그: `../../test/작품인덱스_2026-10-28/swift-test.log`, `../../test/작품인덱스_2026-10-28/release-build.log`.

## 발견 및 조정
기존 UI 테스트가 요청 직전 수동 요약과 용량 관리 문구를 전제하여 새 계약으로 갱신했다. 기존 요약 뷰 자체의 호환 테스트는 별도 생성해서 유지했다. 동시에 들어오는 준비 요청은 마지막에 재스캔 한 번으로 묶어, 준비 중 저장한 변경을 놓치거나 반복 스캔을 쌓지 않도록 했다. 내용 해시를 조각에 보관하여 매 진행 단계마다 원문 전체를 다시 해시하지 않는다.

## 한계와 다음 확인
- 실제 Claude/Codex/Gemini/Grok의 요약·탐색 응답 품질, 로그인/사용량 제한 상황, 큰 작품의 최초 준비 시간은 미검증이다. 테스트용 CLI 통합 성공과 구분한다.
- 검색은 문자열 기반이다. 유사 표현·암시적 관계 누락 가능성이 있으며 전체 검증을 보장하지 않는다. 원문 확인 범위를 답변에 전달한다.
- 외부 앱이 고친 자료는 다음 열기·저장 예약·AI 요청 시 재확인한다. 상시 파일 감시로 AI 요약을 실행하지 않는다.
- 인덱스에는 원문 조각이 포함된다. `.jenanote/`를 동기화하면 해당 캐시도 함께 이동한다.
- 본문과 대화 자체가 500KB를 넘는 요청은 자동 축약하지 않는다.
- 커밋·푸시·릴리스·설치된 앱 교체는 하지 않았다.
