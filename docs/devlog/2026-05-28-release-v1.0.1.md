## 결정

### 버전을 v1.1.0이 아닌 v1.0.1로 한 이유
사용자가 명시적으로 `1.0.1`을 지정했다. 변경 규모(사이드바·글자 색은 새 기능)만 보면 minor bump(v1.1.0)가 SemVer 상 자연스럽지만, 프로젝트 초기 단계에서 사용자가 patch로 묶기로 했다 — 제품 정책으로 존중.

### Release 노트와 코드 스냅샷의 일치
미커밋 변경사항(글자 색 기능) 6개 파일을 먼저 커밋하고 빌드했다. release dmg가 정확히 tag `v1.0.1`의 코드 빌드와 일치한다 — 추적 가능성 확보.

### 커밋 분리
기능 커밋(`feat: add text color formatting…`)과 버전 bump(`chore(release): bump version to 1.0.1`)를 분리. release 커밋만 cherry-pick하거나 revert하기 쉽다.

## 트러블슈팅 — `git push` 실패

처음 push 시 `ssh: Could not resolve hostname github-jenalab`. 원인:

- `~/.ssh/config`의 host alias: `github.com-jenalab` (점 포함)
- `git remote -v`의 URL: `git@github-jenalab:…` (점 없음, 한 글자 누락)

`git remote set-url origin git@github.com-jenalab:jenalab-com/jena-note.git`로 영구 수정. 일회용 우회보다 root cause 수정이 깔끔.
