# 교정 후보 팝오버와 범위별 내 사전

본문 후보에 마우스를 올리거나 편집 커서를 두면 원문과 수정안, 적용·사전 담기를 보여준다. 적용은 해당 어절/구절만 스냅샷 검증 후 변경하며 기존 서식과 Undo를 보존한다. 스크롤·페이지 보기 모두 지원하고, 팝오버가 입력 포커스를 빼앗지 않는다.

사용자가 선택한 대로 등록 기본 범위는 현재 작품이다. 하나의 로컬 저장소에서 항목마다 전체 또는 여러 작품 UUID를 지정한다. 작품 이름은 표시용이며 경로와 북마크로 동명이작을 구분하고 폴더 이동을 추적한다. 작품별 파일의 중복 관리와 완전 공통 사전의 과도한 제외를 피하면서 선택적 공유를 제공한다. 작품 밖 문서는 전체 범위를 명시한다.

Kiwi의 원본 결과를 캐시한 뒤 최소 수정 범위를 사전과 대조한다. 등록 표현 안에 포함된 수정만 제외하여 같은 문장의 다른 오류를 보존한다. 선택 검사에도 동일한 필터를 적용하며 사전 저장과 문서 경로 변경 시 다시 반영한다. 제한된 조사 접미를 지원하고 일반 활용형 추론은 하지 않는다.

편집 > 내 사전에서 검색·등록·표현 및 범위 수정·활성 여부 변경을 제공한다. 등록 창은 명시적 저장 전까지 초안이다. 저장 전 기존 JSON을 보관하고 원자적으로 교체하며, 손상된 파일은 덮어쓰지 않는다. 삭제와 자동 정리는 추가하지 않았다.

검증: 전체 463개 테스트 통과. 새 테스트 12개는 범위 격리·공유·재시작·비활성화·백업·저장 실패·손상·폴더 이동·정확한 표현 필터·캐시 재사용·문서 경로 변경·선택 시트 갱신·스크롤/페이지 팝오버 적용과 Undo·등록 기본값을 확인한다. 검토용 앱은 `.build/JenaNote-Dictionary-review.app`에 별도 빌드한다. 실행 중인 기존 앱과 사용자 원고는 교체하지 않는다.
