# v1.4.0 릴리즈 — 검색 (2026-07-18)

## 요약

문서 내 검색과 파일 전체 검색을 추가했다. 문서 내 검색은 AppKit `NSTextFinder`에 전부 위임하고(코드 최소), 전체 검색은 Foundation-only `FileSearcher` 엔진 + 사이드바 통합으로 구현했다.

## 새 기능

### 문서 내 검색 (⌘F)
- 네이티브 찾기 바 — 전체 매치 하이라이트 + "n/m" 카운트 (`usesFindBar`, `isIncrementalSearchingEnabled`)
- ⌘G 다음 / ⇧⌘G 이전 매치 이동
- ⌥⌘F 찾아 바꾸기 — 서식 유지 + Undo
- 툴바 🔍 버튼
- 읽기 모드(스크롤)에서도 동작. 페이징 모드는 페이지별 분리 텍스트뷰라 미지원(알려진 제약)

### 파일 전체 검색 (⇧⌘F)
- 사이드바 상단 `NSSearchField` — 250ms 디바운스, 백그라운드 검색(키 입력 50ms 예산 불침범)
- 같은 NSOutlineView를 트리 모드 ↔ 결과 모드로 전환 — 파일 그룹(매치 수) + 스니펫(검색어 볼드)
- 결과 클릭 → 인-플레이스 문서 스왑 + 순번 매칭으로 해당 위치 점프·하이라이트
- 검색어 삭제/Esc → 트리 복귀 (펼침 상태 보존 — 진입 시 스냅샷)
- 안내 행: 결과 없음 / 폴더 없음 / 500건 초과 시 일부만 표시

### 엔진 (`FileSearcher`, Infrastructure)
- Foundation-only, AppKit 의존 0 — 등록 폴더의 `.md` 재귀 스캔
- 대소문자·발음 구별 부호 무시 (`[.caseInsensitive, .diacriticInsensitive]`)
- 2MB/파일·500건 총합 상한, 취소 토큰(새 검색 시작 시 이전 검색 무효화)
- 원문 오프셋 대신 **순번 매칭**(파일 내 n번째 occurrence를 에디터 텍스트에서 재탐색) — WYSIWYG 변환(기호 제거) 후 오프셋 불일치 회피, 상세는 ADR-0007

## 개선·수정 (v1.3.0 이후 누적)

- 외부에서 파일이 바뀌면 스크롤 위치를 보존한 채 매끄럽게 자동 리로드 (5801aea)
- 페이징 모드에서 문서 전환 시 리더 뷰 first responder 복원 (22b7f52)
- README 추가 — 소개·설치(Gatekeeper 우회)·빌드·단축키 (fd29704)

## 리뷰 과정에서 잡은 버그 2건

1. **검색 종료 후 트리 펼침 상태 소실** — exitSearch 시점의 캡처가 검색 행을 읽어 스냅샷을 비워버림 → 검색 진입 시 스냅샷 + `reloadTree(capture:)` 게이트로 해결 (2ca931b)
2. **디바운스 창에서 결과 클릭 시 점프 어긋남** — 클릭 시점 필드 값 대신, 결과가 계산된 검색어(`lastSearchQuery`)를 completion에서 짝으로 저장해 사용 (649ffa2)
