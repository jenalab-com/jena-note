# 사이드바 우클릭 및 더블 클릭 파일 관리

- 폴더/파일 우클릭에 이름 바꾸기와 휴지통으로 이동을 추가했다. 폴더에는 새 문서/새 폴더를 추가하고 기존 이름 입력·생성 기능을 재사용한다.
- 우클릭 시 대상 노드를 보관해 선택된 다른 행에 동작하지 않도록 했다. 폴더 탭과 이미지 탭에 동일하게 적용하며 검색 결과 행은 기존 검색 동작을 유지한다.
- 더블 클릭은 이름 바꾸기 시트를 연다. 단일 클릭 동작은 시스템 더블 클릭 간격만큼 지연하고 더블 클릭이나 메뉴 열기에서 취소해 문서를 먼저 열거나 폴더를 먼저 접지 않는다.
- 이름 바꾸기는 기존 목적지를 덮어쓰지 않는다. 문서는 md 확장자를 유지한다. 열린 문서의 URL/창 제목과 해당 폴더 아래 등록 루트의 경로를 갱신하며 편집 중 내용은 그대로 둔다.
- 삭제는 경로와 하위 항목 포함 안내를 확인한 뒤 휴지통으로 이동한다. 영향받는 모든 열린 문서는 NSDocument의 미저장 확인을 먼저 거치며 하나라도 취소하면 삭제하지 않는다. 휴지통 이동 실패 시 문서를 닫거나 등록을 제거하지 않는다.
- 등록 폴더 제거는 기존의 별도 동작으로 유지한다. 휴지통 이동 성공 시 해당 경로 아래 등록된 루트도 목록에서 제거한다.
