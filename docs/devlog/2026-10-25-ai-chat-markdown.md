# AI 답변 마크다운 표시

## 변경과 이유
AI 답변을 일반 문자열로 표시하던 대화 행에서 기존 MarkdownSerializer를 통해 서식 있는 텍스트를 생성한다. 제목, 굵게·기울임, 목록, 인용, 링크, 인라인 코드·코드 블록, 표를 기존 문서 파서의 지원 범위에서 표시한다. 본문 기준 글자 크기를 채팅의 13pt에 맞춰 축소하며 폰트 특성과 코드 강조색을 유지한다.

내 메시지와 상태 안내는 기존 일반 텍스트 표시를 유지한다. 대화 모델에 저장된 원본 응답도 그대로 유지하고 표시만 변환한다. AI 답변의 왼쪽 배치, 바깥 박스 없음, 선택·복사와 편집 불가 동작은 유지된다. 직접 수정 모드의 실제 문서 적용 경로는 변경하지 않는다.

## 결정과 한계
새 웹 뷰나 별도 마크다운 패키지 대신 기존 네이티브 파서를 재사용해 문서와 표시 규칙을 맞췄다. 기존 파서가 지원하지 않는 Markdown 확장 문법을 이번 작업에서 추가하지 않는다. 이미지 참조는 문서 기준 경로 없이 파싱하고 빈 첨부 대신 설명을 표시한다. 링크는 웹·메일 주소만 클릭 가능하게 한다.

AI 행의 자연 너비를 무제한으로 측정하지 않고 실제 채팅 너비로 TextKit 레이아웃을 계산한다. 표·코드 블록이 포함된 답변도 패널 너비 변경 시 다시 배치한다.

## 검증
- AI 표시·레이아웃·편집 관련 테스트 23개 통과.
- 마크다운 표시와 원문 보존, 사용자 메시지 보존, 코드 안의 마크다운 문자 유지, 표와 긴 문장의 너비별 재배치, 이미지 설명 보존을 검증했다.
- 기존 파일은 작업 전 임시 백업했으며 이전 AI 기능과 읽기 모드 변경을 보존했다.
- 전체 테스트 212개 통과. 릴리스 빌드 및 서명 검증 완료: `.build/ai-markdown-preview-CGkN2O/JenaNote.app`.
