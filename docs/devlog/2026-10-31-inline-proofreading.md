# 본문 오류 후보 자동 표시

선택 검사 버튼을 반복해서 눌러야 하는 불편을 줄이기 위해 스크롤·페이지 편집 화면에 자동 표시를 추가했다. 원문 수정이나 새 팝업 없이 수정 후보 부분에 주황색 점선 밑줄만 표시한다.

입력을 0.5초 멈추면 보이는 문장과 인접 문맥을 검사한다. 긴 원고 전체를 타이핑 때마다 검사하지 않으며 스크롤·페이지 이동으로 보이는 부분을 이어 검사한다. Kiwi 엔진을 재사용하고 동일 조각 결과를 제한된 캐시에 보관한다. 한글 조합 중에는 검사하지 않는다.

문자 차이를 원문 UTF-16 범위로 변환해 오타 글자만 표시하고, 빠진 공백은 경계의 두 글자를 표시한다. NSTextStorage에는 속성을 추가하지 않고 NSLayoutManager 임시 표시를 사용해 저장·문서 변경 상태·Undo를 보존한다. 편집 이후 도착한 결과는 폐기하며 화면이 창에서 분리되면 검사와 표시를 정리한다.

새 검증은 변경 부분 범위, 이모지 좌표, 입력 길이·첨부 제한, 한글 조합 대기, 늦은 응답 폐기, 본문·서식·Undo 불변, 스크롤과 페이지 화면의 자동 연결을 확인한다. 기존 선택 검사·적용 기능은 유지한다.

제약: 표시 범위는 현재 화면 우선이며 문서 전체의 교정 완료 상태를 의미하지 않는다. 교정 후보는 Kiwi의 분석 결과에 의존하며 오탐·누락이 가능하다. 긴 조각 경계에서는 문맥이 줄어들 수 있다.

검증용 앱은 `.build/JenaNote-Inline-review.app`에 별도로 빌드하며 기존 검증 앱·설치 앱·사용자 원고는 교체하지 않는다. 커밋·푸시는 수행하지 않는다.

검증 결과: 전체 451개 테스트 통과. 페이지 편집/Undo와 자동 표시를 함께 확인한 관련 20개 테스트도 통과했다. 첫 회귀에서 발견한 TextKit 편집 처리 중 임시 속성 정리 문제는 다음 메인 큐 이벤트로 정리를 미루고 현재 길이로 범위를 제한해 해결했다. `test/InlineProofreading_2026-10-31/annotations.png`에서 원래 밑줄 서식을 유지하며 오타 글자에만 주황색 표시가 추가된 것을 확인했다.

최종 릴리스 빌드 성공: `.build/JenaNote-Inline-review.app`. 기존 코드의 컴파일 경고는 남아 있으나 이번 자동 표시 코드의 새 경고나 오류는 없었다.
