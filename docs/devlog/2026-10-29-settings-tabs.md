# 설정 탭 구성

## 변경과 이유
한 화면에 나열되던 설정을 일반·UI·AI 탭으로 분리했다. 일반은 언어와 자동 저장 켜기/끄기·간격, UI는 컬러 모드와 본문 배경, AI는 기존 AI 설정 화면으로 구성했다.

## 구현 결정
NSTabViewController를 사용해 AI 화면의 생명주기를 연결하고 채팅의 AI 설정 진입은 AI 탭을 직접 선택한다. 기존 설정 키와 저장 동작을 유지한다. 본문 배경은 네 개의 라디오 버튼 색상 칩으로 표시하고 선택 테두리·체크·텍스트 이름·접근성 이름을 제공한다. 칩 색상은 본문의 동적 색상을 사용한다. 언어를 바꾸면 탭/일반/UI 라벨과 AI 페이지를 갱신한다.

## 검증
빌드와 diff 검사 결과 및 화면 확인은 아래 기록한다. 설치 앱 교체는 별도 요청이 없는 한 수행하지 않는다.

검증 결과: 디버그 및 릴리스 빌드, `git diff --check` 통과. 임시 AppKit 렌더링 프로그램으로 620×500 창의 세 탭을 전환해 배치와 색상 칩 선택 표시를 확인했다. 버튼의 오프스크린 시스템 렌더링은 일부 제한이 있어 실제 앱 클릭 검증과 구분한다. 증거 `test/설정탭_2026-10-29/`. 설정 UI 변경으로 별도 회귀 테스트는 추가하지 않았다.

## macOS 기본 색상 선택기로 교체
사용자 피드백에 따라 선택이 불안정한 사용자 정의 4색 라디오 칩을 제거하고 NSColorWell을 적용했다. macOS 색상 패널에서 임의의 색을 선택하면 본문 편집/읽기/소스 화면에 즉시 반영하며 sRGB 구성 요소를 UserDefaults에 보존한다. 기존 프리셋은 읽기 호환하고 새 색을 지정하기 전까지 유지한다. 기본색으로 버튼은 사용자 색을 제거하고 시스템 동적 배경색을 복원한다. 배경은 불투명 색으로 저장하며 문서 내용/내보내기에 영향을 주지 않는다.

기본 색상 선택기 검증: NSColorWell 액션을 직접 보내 임의 RGB 색의 본문 반영·설정 보존 및 기본색 복원을 확인했다. 관련 11개 테스트, 디버그/릴리스 빌드 및 diff 검사 통과. UI 탭 오프스크린 배치 확인. macOS 색상 패널 직접 마우스 조작은 미검증이며 설치 앱은 교체하지 않았다.

최종 커밋 전 통합 검증: 전체 427개 테스트 통과(실패 0). README와 현재 명세의 이전 4색/경로 기반 백업 설명을 최종 구현으로 맞췄다. 최종 테스트 로그: `test/원고이력_2026-10-29/final-swift-test.log`.
