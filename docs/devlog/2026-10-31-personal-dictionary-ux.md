# 내 사전 사용 흐름 개선

## 문제
뜻 검색 사전과 맞춤법 허용 표현 목록의 목적이 구분되지 않고, 검색·신규 등록·편집·작품 범위가 수직으로 섞여 다음 행동을 알기 어려웠다.

## 변경
- 제목과 안내에서 맞춤법 검사에서 허용하는 이름/작품 용어를 관리하는 화면임을 명시한다.
- 왼쪽에 표현 추가·등록 목록 검색·상태 목록을, 오른쪽에 등록/편집 폼을 둔다.
- 표현 입력 → 적용 범위 선택 → 등록 순서로 번호와 구체적인 버튼 이름을 제공한다.
- 새 표현 등록/기존 표현 변경 저장을 구분하고 필수 입력·범위가 없으면 저장을 비활성화한다.
- 현재 작품을 표시하고 경로는 툴팁으로 제공한다. 전체 작품 선택 시 불필요한 작품 선택 목록을 숨긴다.
- 목록 없음과 검색 결과 없음의 안내를 분리한다. 검색 중 목록 재선택으로 편집 중 입력이 덮이지 않도록 갱신 이벤트를 구분한다.

## 범위
사전 저장 형식·작품별 적용 규칙·검사 엔진은 변경하지 않는다. 등록 비활성화는 기존대로 체크를 끄고 변경 저장한다.

## 검증
기존 폼 테스트의 저장 버튼 탐색을 안정적인 식별자로 바꾸고, 새 항목/편집 버튼 전환과 입력 전 저장 비활성화·입력만으로 미저장 유지 확인을 추가했다. 결과는 아래 기록한다.

검증 결과: 폼 테스트 통과, 오프스크린 렌더링에서 작품 목록의 위쪽 정렬을 보정했다. 일부 사전 테스트 묶음 실행에서 작품 전환 비동기 검사가 시간 초과했으나 변경 전 단독 검사 및 최종 전체 463개 테스트는 통과했다. 시험 로그를 보존하며 검사 엔진은 수정하지 않았다. 증거 `test/사전UX_2026-10-31/`.
릴리스 빌드와 `git diff --check` 통과. 설치 앱 교체·커밋·푸시는 수행하지 않았다.

## 사용자 재지정: 상하 배치와 한 줄 등록
좌우 분할/설명/단계 질문/검사 제외 체크를 제거했다. 상단은 표현 입력·전체/작품 선택·표현 등록 한 줄, 하단은 검색과 목록이다. 등록은 항상 enabled=true로 저장하고 입력을 비우며 선택한 범위는 유지한다. 현재 작품이 있으면 처음에 선택한다. 기존 항목 선택 시 같은 줄에서 수정하며 이전 다중 작품 범위는 별도 선택 항목으로 보존한다. 오류와 짧은 빈 목록 상태만 표시한다.
한 줄 등록 최종 검증: 기존 폼 통합 테스트를 새 구조로 갱신하여 현재 작품 기본 선택, 저장 전 미등록, 전체 작품 선택 등록, 항상 제외 활성, 등록 후 입력 비움/선택 범위 유지를 확인했다. 테스트·오프스크린 렌더링·릴리스 빌드·diff 검사 통과. 이번 재조정에서는 전체 테스트를 반복하지 않았다. 설치 앱은 교체하지 않았다.

## 사전 추가 용어와 다중 삭제
화면 제목/등록 버튼은 사전 추가, 입력/목록은 단어로 변경했다. 각 행 앞 체크박스와 전체 선택/선택 삭제 버튼을 제공한다. 체크 상태는 행 번호 대신 UUID로 관리하고 검색 시 보이지 않는 항목을 체크에서 제외한다. 삭제 대상이 편집 중이면 입력 폼을 초기화한다. 저장소의 백업+원자 저장 경로를 등록/삭제가 공유하며 삭제 후 한 번만 변경 알림을 발행한다. 삭제 실패 시 메모리 상태를 변경하지 않는다.
다중 삭제 검증: 선택 삭제/미선택 보존/저장소 재열기/알림 1회, 실패 시 파일과 메모리 보존 및 체크박스 실제 액션 경로 테스트 통과. 사전 단독 묶음의 기존 작품 전환 비동기 시간 초과는 재현됐으나 최종 전체 465개 테스트는 실패 0으로 통과했다. 릴리스 빌드·diff 검사 통과, 화면 렌더링 확인. 설치 교체·커밋·푸시 없음.
