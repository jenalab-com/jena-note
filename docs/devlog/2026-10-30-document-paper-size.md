# 문서 크기와 고정 용지 치수자

## 요구와 결정
보기 설정에 문서 크기 선택을 추가한다. A3/A4/A5/A6, ISO B3/B4/B5/B6, JIS B4/B5, Letter/Legal과 기존 자동 읽기 폭을 제공한다. B계열은 혼동하지 않도록 표준과 mm 치수를 이름에 함께 표시한다. 기준: https://github.com/apple/cups/blob/master/cups/pwg-media.c

용지 선택은 기존 보기 설정과 같은 앱 공통 설정이며 Markdown 원문에는 쓰지 않는다. 세로 방향 규격을 사용하고, 현재 요청의 범위는 화면 조판과 가로 치수자다. 인쇄/Word/한글 내보내기 용지 설정을 바꾸는 기능은 포함하지 않는다.

## 구현
- 문서 전체 폭과 본문 폭을 분리한다. 본문 폭은 용지 폭에서 좌우 여백을 뺀 값이다.
- 규격 용지에서 가로 치수자 0은 종이 왼쪽 끝이다. 여백 핸들은 본문 영역만 바꾸고 용지는 확대하지 않는다. 더블클릭도 여백만 초기화한다.
- 스크롤 보기는 실제 용지 폭을 유지하며 좁은 창에서는 가로 스크롤한다. 치수자는 가로 스크롤 위치를 따라간다.
- 페이지 보기는 선택 용지의 폭/높이로 조판하고 큰 용지는 화면에 맞춰 축소 표시한다. 창 크기를 바꿔도 용지와 본문 조판 치수는 유지한다.
- 용지 선택 시 책 보기로 전환한다. 모바일 보기는 기존 고정 모바일 폭이며 용지 설정은 책 보기에서 적용한다.
- 세로 치수자는 추가하지 않는다. 기존 자동 폭/폭 확장 동작은 자동 모드에서 유지한다.

## 검증
치수 변환, ISO/JIS 구분, 핸들의 용지 확대 방지, 비대칭 여백, 좁은 창 스크롤 본문 폭, 페이지 치수 유지 및 초기화를 검증한다. 테스트 창 크기를 실제 배치하지 않아 실패했던 초기 재현은 창 배치를 수행해 바로잡았다.

검증 결과: 전체 430개 테스트 통과. 렌더링 확인에서 축소 페이지 번호 위치를 수정한 후 치수자 관련 13개 테스트 재통과 및 디버그/릴리스 빌드·diff 검사 통과. 스크롤/페이지 화면을 오프스크린 렌더링으로 확인했다. 증거 `test/문서크기_2026-10-30/`. 설치 앱 교체·커밋·푸시는 하지 않았다.
