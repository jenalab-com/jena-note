# 초기 작품 파악을 Foundation Models로 분리

## 변경 이유와 설계
초기 파악에 집필용 CLI 사용량을 쓰지 않도록 사용자가 요청했다. 설계/계획/기획 로그/ADR-0016을 먼저 작성했다.
- 설계: `../superpowers/specs/2026-10-28-foundation-work-index-design.md`
- 계획: `../superpowers/plans/2026-10-28-foundation-work-index.md`

## 구현
- `AIWorkLocalSummarizer`: OS/모델 가용성 확인, 새 세션, 원문 언어 감지, 한국어 지시, 이름/관계/금지/예외 보존 요청. 온디바이스 전용이며 외부 호출 없음.
- 앱 전체 추론 직렬화, 조각별 120초 취소 요청, 사용자 취소 전파. SDK가 취소를 처리한 뒤 다음 조각으로 진행하므로 강제 종료 시간은 보장하지 않는다.
- 인덱스 v2/2,400바이트 조각, 원문 전량 보존, apple/excerpt 출처와 이유 저장. 변경 없는 요약 재사용, 가용성 변화 또는 명시 재시도는 발췌만 재시도. 공백 조각은 추론하지 않는다.
- 저장소의 provider/model/외부 토큰 집계를 제거. 탐색기의 CLI 생성 계약을 별도로 유지한다.
- 준비 UI는 기기 내 요약/발췌 개수와 사유를 표시한다. 상세 사유는 툴팁 및 조각 목록. 기존 수동 요약 파일 유지.

## 실기에서 발견하고 수정한 점
macOS 26.5.2 / Xcode Swift 6.3.3 SDK 26.5. Foundation Models available, 한국어 지원 true.
1. 직접 API의 첫 가상 설정 샘플은 guardrailViolation으로 실패했다. 로그 `device-smoke.log`. 따라서 모델 거절을 포함한 실패를 원문 발췌로 처리하는 설계를 유지했다.
2. 영어 지시로 한국어 설정을 요약하니 영어 출력과 이름 음역/성별 추정이 나왔다. `adapter-smoke-before-prompt-fix.log`.
3. 언어 감지 및 한국어 지시로 보완한 실제 프로덕션 어댑터 실행은 설정 약 1.93초, 사건 약 0.81초. 설정 샘플에서 도서관 휴일, 형제 관계 방향, 존댓말/반말, 3권/연구원 5권 예외가 유지됐다. 사건 샘플은 책갈피 반환/책 대여를 보존했지만 색·할머니 유래 등 세부사항은 생략됐다. 따라서 요약은 검색 힌트로만 쓰며 원문을 사실 근거로 쓰는 원칙을 유지한다.
실기 검증은 가상 원문 두 조각이며 실제 장편 작품 전체의 품질·시간을 입증하지 않는다.

## 검증 기록
`../../test/FoundationModels_2026-10-28/`에 테스트/빌드/실기 로그를 보존한다. `adapter-smoke.swift`는 도메인 타입 최소 스텁과 실제 `AIWorkLocalSummarizer.swift`를 함께 컴파일하는 재현 도구이며 별도 요약 구현을 사용하지 않는다.

## 남은 실사용 확인
대규모 작품의 처음 준비 시간/메모리, macOS 11~25 실기 실행, 실제 작품의 인물·복선 검색 품질. 설치된 앱 교체·커밋·푸시·릴리스는 수행하지 않는다.
