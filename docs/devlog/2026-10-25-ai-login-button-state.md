# AI 로그인 버튼 상태

## 변경과 이유
재확인에서 정상 AI 응답을 받은 제공사·실행 파일 조합은 로그인 버튼을 `로그인됨`으로 표시하고 비활성화한다. 제공사를 바꿨다가 돌아와도 설정창 수명 내 확인 상태를 유지한다. 다른 실행 파일 경로는 확인 상태를 공유하지 않는다.

연결 검사 중에는 중복 로그인 실행을 막고, 재확인 실패 시 다시 로그인할 수 있게 활성화한다. 모델이 테스트 문구와 다른 정상 응답을 반환해도 인증이 된 것은 확인되므로 로그인 버튼은 비활성화하고 연결 테스트의 예상 응답 불일치는 별도로 표시한다.

## 범위
로그인 확인은 기존 재확인 흐름을 사용한다. 설정을 열 때 임의의 유료 모델 요청을 추가하지 않는다. 확인 상태는 영구 저장하지 않으며 앱 재시작 후 재확인한다. 기존 CLI 인증 정보는 읽거나 변경하지 않는다.

## 검증
- AI 테스트 17개 통과: 성공/검사 중 비활성화, 제공사 전환 후 상태 유지, 실행 파일 변경 시 상태 분리, 실패 후 활성화.
- 테스트의 다른 실행 파일 예시를 macOS에 실제 존재하는 `/bin/sh`로 수정했다. 최초 `/bin/false`는 존재하지 않아 미설치 상태로 판정되는 테스트 오류였다.
- 릴리스 빌드 성공: `.build/ai-login-preview-0QQadV/JenaNote.app`.
- 기존 실행 앱과 앞선 빌드는 보존했다.
