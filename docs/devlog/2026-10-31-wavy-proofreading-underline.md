# 교정 후보 밑줄 위치와 물결 점선

잘 보이지 않는다는 피드백에 따라 교정 후보 표시를 글꼴 하단에서 2.5pt 아래를 중심으로 하는 주황색 물결 점선으로 변경했다. 진폭 1.3pt, 주기 6pt, 선 두께 1.8pt와 둥근 선 끝을 사용한다.

AppKit 기본 밑줄 속성으로는 모양과 위치를 함께 제어할 수 없어 ProofreadingLayoutManager가 교정 후보 전용 임시 표식만 별도로 그린다. 스크롤·페이지 레이아웃에 동일하게 적용하며, 일반 밑줄은 기존 AppKit 그리기로 전달한다. 글자 위치·줄 높이·문서 서식과 교정 판정은 유지한다. 표시가 글리프 영역 아래까지 내려가므로 추가·제거 시 텍스트 뷰를 다시 그려 잔상을 방지한다.

기존 실행 앱을 교체하지 않고 `.build/JenaNote-WavyUnderline-review.app`에 별도 빌드한다.

검증: 전체 451개 테스트와 릴리스 빌드 통과. 점선 간격 최종 조정 후 자동 표시 테스트 7개도 통과했다. `test/WavyUnderline_2026-10-31/annotations.png`에서 일반 밑줄은 그대로 유지되고 오류 후보만 아래쪽 주황 물결 점선으로 표시되는 것을 확인했다. 둥근 선 끝이 서로 붙지 않도록 대시 1.4pt/간격 2.8pt를 사용한다.
