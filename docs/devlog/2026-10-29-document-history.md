# 원고 버전 이력

## 변경과 이유
기존 백업을 Git의 내용 주소 방식과 불변 이력 메타데이터로 확장했다. 동일 내용은 SHA-256 객체를 공유하고 이전 이력 ID를 기록한다. 별도 Git 설치는 필요 없다.

## 기능과 결정
- 이름 붙인 버전은 현재 미저장 원고로 만들 수 있고 자동 정리에서 보호한다.
- 이름 없는 시점은 최근 100개, 자동 기록 최소 간격은 5분이다.
- 이력 창에서 선택 버전과 현재 원고를 줄 단위로 비교한다. '-'는 이전, '+'는 현재다. 비교 비용이 큰 원고는 원문 보기를 안내한다.
- 복원 전 현재 내용을 보관하고 복원 시점을 새로 기록한 뒤 본문을 바꾼다. 기록 실패 시 본문 변경을 하지 않는다.
- 문서 UUID와 macOS 북마크로 로컬 이름 변경/이동을 추적한다. 기존 경로 해시 백업은 최초 조회 때 이전하며 기존 JSON은 읽기 호환한다.
- 객체 손상은 명시적 읽기 오류로 처리한다.

## 한계와 절충
브랜치, 병합, 변경 수락/거절, 이미지 객체, 클라우드 동기화는 제외했다. 다른 볼륨 복사 등 북마크로 추적되지 않는 이동은 별도 이력이 될 수 있다. 부모 시점은 보관 정책으로 정리될 수 있으며 이번에는 객체 가비지 수집을 하지 않아 삭제된 시점의 내용 객체가 디스크에 남을 수 있다. 비교는 문장 의미 분석이 아닌 줄 단위이며 Markdown 원문 기준이다.

## 검증
이름 붙인 버전 보호, 객체 중복 제거, 부모 연결, 저장소 재열기, 복원 강제 시점, 파일 이름 변경, 기존 백업 이전, 객체 손상, 비교 방향/크기 제한을 테스트한다. 전체 테스트와 릴리스 빌드 결과는 아래 기록한다.

전체 422개 테스트, `make build`, `git diff --check` 통과. 증거: `test/원고이력_2026-10-29/`. 실제 GUI 조작 검증과 설치 앱 교체는 수행하지 않았다.

## 비교 화면 개선
기존 기호만 붙인 원문으로는 변경 위치와 비교 대상을 알아보기 어렵다는 실사용 피드백을 반영했다. 선택 버전/현재 미저장 원고를 좌우로 나누고 줄 번호, 수정/추가/삭제 색상과 기호, 변경 줄 수, 이전/다음 변경 이동을 제공한다. 동일한 행 높이와 세로 스크롤 동기화로 두 버전 위치를 맞춘다. 긴 줄은 줄바꿈 대신 가로 스크롤을 제공한다. 수정은 인접한 삭제·추가 구간을 행 순서대로 대응시키는 표시이며 의미 분석이나 병합 기능이 아니다.

비교 개선 검증: 전체 424개 테스트 통과 후 화면 배치 테스트를 추가해 이력 관련 7개 테스트도 통과했다. 좌우 열 너비/높이·강조 속성을 검증하고 오프스크린 PNG를 확인했다. 릴리스 빌드 및 diff 검사 통과. 실행 중 설치 앱은 교체하지 않았다. 증거 `test/원고이력_2026-10-29/comparison-*`.

## 전체 변경 위치 막대
변경된 줄을 찾으려고 스크롤해야 한다는 피드백에 따라 좌우 비교 사이에 전체 원고의 변경 위치 막대를 추가했다. 수정(주황)·추가(초록)·삭제(빨강) 위치를 원고 전체 행 수에 비례해 표시하며 클릭하면 가장 가까운 변경 행으로 이동한다. 현재 보이는 범위는 옅은 배경으로 표시한다. 기존 이전/다음 버튼의 탐색 위치도 클릭한 변경으로 갱신한다. 빈 원고/변경 없음은 클릭해도 이동하지 않는다.

변경 위치 막대 검증: 관련 8개 테스트(위치 비율·클릭 선택·빈 목록 포함), 오프스크린 렌더링 확인, 릴리스 빌드 및 diff 검사 통과. 증거 `test/원고이력_2026-10-29/change-map-*`. 설치 앱 교체 없음.
