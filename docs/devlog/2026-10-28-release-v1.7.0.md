# v1.7.0 릴리스

## 변경
- Makefile 및 Info.plist 버전 1.7.0.
- 작품 자동 인덱싱·원문 탐색, Foundation Models 온디바이스 초기 요약, 채팅 입력창 통합과 한 줄 사용 현황.
- README 다운로드 파일명과 Foundation Models 설계 문서의 배포 최소 OS(13, Swift 패키지 타깃 11) 표기를 정정.

## 검증 및 패키징
- 전체 397개 테스트 통과, 릴리스 빌드 성공.
- Apple Silicon arm64, macOS 13 이상. Foundation Models는 macOS 26 이상에서 런타임 가용성 확인, weak link 유지.
- 기존과 동일하게 ad-hoc 서명, 공증 없음.
- DMG 생성 뒤 남은 디스크 이미지 장치가 검증을 잠가 EAGAIN 발생. 생성 작업의 /dev/disk4 연결을 해제한 뒤 체크섬 검증 성공.
- 읽기 전용 마운트 후 내부 앱 버전 1.7.0, 서명 무결성, 로컬 실행 파일 SHA-256 일치 및 Applications 링크 확인.
- DMG SHA-256: `26ddce68d72e37c80a0fcdc556bf14cb5528434e80043b11bcba2f043fdcc466`.
- 실행 로그: `../../test/릴리스_1.7.0_2026-10-28/`.

## 릴리스 노트
## 작품 자동 파악과 원문 탐색
- 설정 자료와 집필 폴더를 등록하면 작품을 자동으로 인덱싱하고, 변경된 조각만 갱신합니다.
- 초기 요약은 Foundation Models로 기기 안에서 처리하므로 집필용 외부 AI 사용량을 쓰지 않습니다.
- 기기 내 모델을 사용할 수 없거나 요약에 실패하면 원문 발췌로 검색을 유지합니다. 기기 내 요약과 발췌는 구분해서 표시합니다.
- 질문별 자료 탐색과 가이드·직접 수정은 선택한 CLI 모델을 사용합니다. 필요한 원문을 찾아 참고하고 현재 화보다 뒤의 글은 요청에서 제외합니다.
- 준비 중에도 편집할 수 있고, 캐시 재사용·중지·재시도를 지원합니다. 기존 수동 요약 파일은 보존합니다.

## 간결한 AI 채팅
- 대화 영역 배경을 통일하고 입력창 안에 가이드/직접 수정, 모델 선택, 보내기/중지 버튼을 모았습니다.
- Enter로 전송하고 Shift+Enter로 줄을 바꿉니다. 한글 조합 중 Enter는 전송하지 않습니다.
- 입력창 아래에 사용률과 리셋까지 남은 시간을 한 줄로 표시하며 재조회 아이콘을 제공합니다.

## 설치 및 확인 사항
- `JenaNote.dmg`를 열어 앱을 Applications로 끌어 넣습니다.
- 배포 파일은 Apple Silicon(arm64), macOS 13 이상용입니다. 기기 내 AI 요약은 macOS 26 이상과 사용 가능한 Apple Intelligence 모델이 필요합니다.
- v1 인덱스는 새 조각 규격으로 한 번 재구성합니다. 원고와 기존 수동 요약 파일은 변경하지 않습니다.
- 기존과 동일하게 ad-hoc 서명이며 Apple 공증은 포함하지 않습니다.
- 전체 397개 테스트, 릴리스 빌드, DMG 체크섬·내부 앱 버전·서명 검증을 통과했습니다. 실제 한국어 샘플 요약을 확인했으며 장편 전체의 품질·준비 시간은 추가 실사용 확인 대상입니다.
