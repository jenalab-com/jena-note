# v1.8.0 릴리스

## 변경
- Makefile 및 Info.plist 버전 1.8.0.
- v1.7.0 이후: 백그라운드 요약과 채팅 문맥 분리, 원고 버전 이력·문서 끝 주석·본문 배경색·자동 저장 설정·설정 탭, 규격 용지와 고정 치수자, Kiwi 기반 본문 오류 표시·선택 문장 검사·내 사전.
- 이번 묶음: Kiwi 0.24.1 소스 동봉 빌드, 맞춤법 규정 기반 교정 보완, 오픈소스 라이선스 창, 클라우드 드라이브 문서 전환 안정화와 스크롤 복원 크래시 수정.
- README에 맞춤법 규정 기반 보완·오픈소스 라이선스 항목 추가.
- `.gitattributes`로 `Vendor/Kiwi/source`의 줄바꿈 변환을 막아 새 클론에서도 Kiwi 소스 지문이 일치하도록 했다(로컬 클론으로 확인).

## 검증 및 패키징
- 전체 485개 테스트 통과, 릴리스 빌드 성공.
- Apple Silicon arm64, macOS 13 이상. 기존과 동일하게 ad-hoc 서명, 공증 없음.
- `make dmg`는 번들 서명 단계가 없어 실행 파일의 링커 서명만 남는다(`codesign --verify --deep --strict` 실패). 1.7.0과 같이 `make build` 후 번들을 `codesign --force --deep --sign -`으로 서명하고, Makefile의 DMG 단계를 서명된 번들로 실행했다. 첫 미서명 DMG는 폐기했다.
- 읽기 전용 마운트 후 내부 앱 버전 1.8.0, 서명 유효·Designated Requirement 충족, 실행 파일 SHA-256 로컬 서명본과 일치, Applications 링크, Kiwi 모델 0.24.1과 라이선스 고지 10개 포함 확인.
- Kiwi 모델 포함으로 DMG가 약 107MB(1.7.0은 약 7MB).
- DMG SHA-256: `f43e537b20fe14841058ab2c3b9533a3a04aba68438c348486fd6b633120f779`.
- 실행 로그: `../../test/릴리스_1.8.0_2026-10-31/`.
