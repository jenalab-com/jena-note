# 원문 보기와 인라인 코드 구분

## 요청과 변경
`</>` 아이콘이 원문 보기로 오해되는 문제를 해결하기 위해 툴바에 `원문 보기`와 `인라인 코드`를 별도 텍스트 버튼으로 제공한다. 보기 메뉴에도 원문 보기를 추가하고, 서식 메뉴의 코드 항목도 인라인 코드로 명시했다.

- 원문 보기: 현재 문서가 저장될 때의 마크다운을 별도 읽기 전용 창에 표시한다. 저장 전 변경사항을 포함하며 선택·복사, 전체 복사, 찾기를 지원한다. 텍스트 파일은 마크다운 변환 없이 저장될 일반 텍스트를 표시한다.
- 인라인 코드: 선택한 글의 코드 서식을 적용·해제한다. 선택 영역이 없을 때는 버튼을 비활성화하고 툴팁에 선택이 필요하다고 안내한다.
- 표시 조판이 코드의 고정폭 글꼴을 일반 본문 서체로 덮던 문제를 수정했다. 인라인 코드와 코드 블록은 원래 글꼴을 배율만 적용해 표시한다.

## 보존과 동기화
원문 창은 파일을 다시 읽거나 저장하지 않고 문서의 기존 직렬화 경로를 사용한다. 최초 파일 바이트를 그대로 보관하는 뷰가 아니라 현재 편집 내용을 저장할 때의 표현임을 안내한다. 문서 전환·외부 리로드·AI 및 서식 편집·Undo에 맞춰 갱신하고, 연속 타이핑에서는 갱신을 0.2초 뒤로 모아 직렬화 비용을 줄인다. 부모 문서 창을 닫으면 해당 원문 창도 닫는다.

작업 전 변경 대상 소스를 임시 백업했다. 기존 AI·통합 편집·페이지 기능과 진행 중인 변경은 보존한다.

## 검증
전체 테스트 220개 통과. 원문 표시의 읽기 전용·원본 불변·미저장 내용 반영, 일반 텍스트 표시, 문서 교체 후 내용 정리, 코드 서식과 Undo 갱신, 창 종료, 별도 툴바 액션과 선택 상태에 따른 활성화, 코드 고정폭 글꼴과 직렬화 왕복을 검증했다.
