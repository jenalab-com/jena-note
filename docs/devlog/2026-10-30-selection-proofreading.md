# 선택 문장 검사

문장을 선택한 뒤 툴바의 문장 검사 또는 편집 메뉴로 Apple Intelligence의 기기 내 교정을 요청한다. 최대 500자·UTF-8 1,500바이트이며 외부 서비스로 전환하지 않는다. 비교 시트의 적용 버튼을 눌러야 문서가 바뀌고 한 번의 실행 취소로 복원된다. 검사 중 원문이 바뀌면 반영하지 않는다.

작품 요약과 직렬 추론 큐를 공유한다. 선택 검사는 대기 중인 요약보다 우선하고 실행 중인 요약은 유지한다. 대기를 포함한 30초 제한으로 사용자 대기를 끝내며, 모델 취소가 늦으면 슬롯은 실제 반환까지 유지한다.

검증:
- `swift build -c release --product JenaNote` 성공.
- 전체 439개 테스트 통과. 선택 범위, 비교 후 적용, Undo, 페이지 모드, 원문 변경 충돌, 취소, 큐 우선순위 및 시간 제한을 포함한다.
- 실제 모델 available 상태에서 직접 만든 예문 4개를 검사했다. 띄어쓰기와 오타 2개를 교정했고, `안녕 하세요.`의 띄어쓰기는 놓쳤다. 고유명사 예문은 유지했다. 각 응답은 약 0.6~8초였다.
- 상세 결과와 실행 방법: `test/Proofreading_2026-10-30/`.
- 비트맵 렌더는 시스템 레이어가 일부 누락되므로 실제 창 전체의 외관 검증을 대신하지 않는다.

원문과 제안을 확인하는 보조 기능이다. 교정 정확도, 문체와 고유명사 보존을 보장하지 않는다. 앱 설치·실행 교체와 커밋·푸시는 이번 작업에 포함하지 않았다.
