# 선택한 폴더에 문서·폴더 생성

## 변경
- `+`는 기존 폴더를 사이드바에 등록하는 원래 동작으로 복원했다. 툴팁도 기존 폴더 등록으로 구분했다.
- `folder.badge.plus`는 선택 폴더 아래에 새 폴더를 만들고, `doc.badge.plus`는 빈 `.md` 파일을 만든다. 파일을 선택하면 부모 폴더를 사용한다. 선택 항목이 없거나 접근할 수 없으면 생성 버튼을 비활성화한다.
- 이름 입력 시 대상 경로를 표시한다. 확장자가 없는 문서 이름에는 `.md`를 붙이고, 이미 `.md`/`.MD`이면 중복하지 않는다.
- 새 문서는 기존 사이드바 문서 교체 경로로 현재 창에 연다. 기존 문서의 미저장 변경 확인은 유지된다. 파일 메뉴의 ⌘N 동작은 변경하지 않는다.
- 새 폴더가 즉시 보이도록 빈 폴더도 트리에 표시한다. 생성 항목의 조상 폴더를 펼치고 선택하며, 파일 감시 갱신에서도 선택한 폴더를 보존한다.

## 보호와 결정
- 파일은 `Data.write(.withoutOverwriting)`, 폴더는 원자적 `mkdir`로 생성해 기존 항목을 덮어쓰거나 같은 폴더를 재사용하지 않는다. 실패는 오류 시트로 표시한다.
- 빈 이름, 점으로 시작하는 이름, 경로 구분자, NUL을 거부한다. 존재하지 않는 부모는 자동 복구하지 않는다.
- 생성 후 기존 문서의 저장 확인에서 취소하면 현재 문서를 유지한다. 이미 사용자가 이름을 확정하여 만든 새 파일은 폴더에 남겨 두며 임의로 삭제하지 않는다.
