## 결정

### 저장 형식 — 표준 `![]()` + 크기 지정 시 `<img width>`
크기 없는 이미지는 CommonMark 표준 `![]()`로 두어 이식성을 지키고, 크기 지정이 필요한 경우만 inline HTML `<img>`로 저장한다. 비표준 확장(`![](path =WxH)`)이나 Obsidian 전용 문법 대신, 다수 렌더러가 지원하는 HTML 태그를 택했다.

### 저장 위치 — 노트 옆 `attachments/`
이미지는 노트 파일과 같은 폴더의 `attachments/`에 복사한다. 노트 단위로 첨부가 묶여 이동·백업이 쉽다. 트레이드오프: 노트를 다른 폴더로 옮길 때 `attachments/`도 함께 옮겨야 경로가 유지된다.

### 본문 이미지 크기 — `cellFrame` 대신 `bounds` 직접 제어
초기엔 커스텀 `NSTextAttachmentCell.cellFrame`으로 크기를 정했으나, 글리프 캐시 때문에 속성 변경 시 재측정이 트리거되지 않아 렌더링에 반영되지 않았다. `NSTextAttachment.bounds`를 직접 설정하고 리사이즈·로드·크기변경 시 `relayoutImageAttachments()`로 다시 계산하는 방식으로 전환해 글리프 캐시와 무관하게 확실히 반영되도록 했다.

### 사이드바 — 문서 화면을 가로채지 않음
초안에서는 폴더 클릭 시 우측 본문 영역을 썸네일 그리드로, 이미지 클릭 시 크게 보기로 교체했으나, "문서 편집기"라는 제품 정체성과 어긋난다는 피드백을 받아 제거했다. 우측 문서 화면은 절대 바꾸지 않고, 미리보기는 hover 팝업으로, 삽입은 드래그로 처리한다.

### 알려진 미검증 항목 (수동 e2e 권장)
GUI 동작은 헤드리스로 검증 불가해 사람이 직접 확인한다: 드래그앤드롭 삽입, 본문 내 이미지 이동, hover 미리보기, 우클릭 크기 변경, 읽기 모드 이미지 폭 맞춤.
