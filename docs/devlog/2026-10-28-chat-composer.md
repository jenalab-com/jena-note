# AI 채팅 입력창 정리

## 요청과 디자인 기준
사용자 제공 대화 샘플처럼 전체를 한 바탕으로 이어 주고 하단 입력창에 기능을 모은다. 대상은 글을 쓰면서 AI에 요청하는 작가이며, 개념은 ‘집필 흐름을 끊지 않는 단일 입력창’이다. 기존 AppKit 글꼴·시맨틱 색·패널 폭을 유지하고 새 브랜드 색이나 장식은 도입하지 않는다. 라이브는 제외하며 이미지 첨부·썸네일도 사용자가 최종 제외했다.

## 변경
- 투명한 대화 스크롤 영역과 단일 패널 바탕. 사용자 말풍선 외곽선을 제거하고 입력창은 약한 채움으로 구분.
- 입력창 안에 작품 문맥, 선택한 글(선택이 있을 때만), 입력부, 가이드/직접 수정, 모델 메뉴와 보내기/중지 단일 버튼 배치.
- 모델의 편집 가능한 콤보박스를 테두리 없는 메뉴로 변경. 사용자 지정 모델은 별도 ID 입력 시트로 유지.
- 사용량/새로고침은 정보 버튼 팝오버로 이동. 문서 이름과 AI 설정은 간결한 상단 헤더.
- Enter 전송, Shift+Enter 명시적 개행. IME 조합 중 Enter는 원래 입력기로 전달. 대기 중 Enter로 중복 요청하거나 중지하지 않음.
- 준비/탐색/답변 대기 중 버튼이 중지로 전환되고 완료/오류/취소 후 보내기로 복귀.

## 검증
키 이벤트 테스트(Enter/Shift+Enter/한글 조합/대기), 260·300·600pt 레이아웃, 실제 CLI 어댑터를 이용한 테스트용 응답의 버튼 전환, 같은 버튼으로 취소 및 초안 복원, 기존 자동 인덱스/편집기 회귀를 확인한다. 라이트/다크 AppKit 스냅샷으로 패널 바탕과 하단 배치를 확인한다. 실제 한글 입력기 사용감은 별도 실사용 확인 대상이다.

**결과:** 전체 386개 테스트 통과(실패 0), `make build` 릴리스 앱 생성 성공. `git diff --check` 통과.

실행 결과와 이미지: `../../test/채팅입력창_2026-10-28/`.
빌드 앱: `.build/JenaNote.app`. 설치된 앱 교체·커밋·푸시·릴리스는 수행하지 않는다.

## 추가 요청: 입력창 아래 사용 현황
입력창 아래에 한도별 사용률과 리셋까지 남은 시간을 상시 표시한다. 하루 이상은 `2d 3h`, 미만은 `5h 20m` 형식이며 1분마다 남은 시간을 갱신한다. 정확한 리셋 일시는 툴팁으로 확인한다. 제공되지 않는 시간은 `—`, 사용량 자체가 제공되지 않으면 기존 안내를 표시하며 임의의 0%를 만들지 않는다. 기존 정보 팝오버의 새로고침도 유지한다.

추가 변경 검증: 전체 387개 테스트 통과, 릴리스 빌드 성공. 결과는 `usage-swift-test.log`, `usage-release-build.log`에 보존.

### 사용 현황 한 줄 표시
최종 요청에 따라 `18% 1h 58m · 65% 1d 10h · 100% Fable` 형식으로 축약하고 끝에 재조회 아이콘을 배치했다. 모델별 한도는 시간 대신 모델명을 표시하며, 상세 한도 이름과 정확한 리셋 일시는 툴팁에 유지한다. 조회 중에는 재조회 버튼을 비활성화한다. 좁은 폭에서는 한 줄을 유지하고 말줄임 처리한다.

한 줄 표시 검증: 전체 388개 테스트 통과, 최종 배치 조정 후 관련 13개 테스트 통과, 릴리스 빌드 성공. 로그는 `inline-*.log`로 보존.
