# AI 채팅창 크기와 대화 표시

## 변경과 이유
사용자가 제공한 대화 화면을 기준으로 내 메시지는 오른쪽의 둥근 회색 박스에, AI 답변은 왼쪽에 박스 없이 표시한다. 메시지 텍스트는 기존처럼 선택하고 복사할 수 있다.

본문과 채팅창 사이 구분선을 드래그해 너비를 조절한다. 기본 너비는 300pt, 최소 260pt, 최대 600pt로 제한한다. 최대치는 최초 기본 너비의 2배이며 재개방할 때마다 늘어나지 않는다. 같은 문서 창에서 채팅창을 닫고 다시 열면 조절한 너비를 유지한다. 높이는 문서 창을 따른다.

메시지별 TextKit 레이아웃으로 너비 변경 시 긴 한글·영문·이모지 메시지도 다시 줄바꿈한다. 텍스트의 고유 너비가 분할 창 크기를 고정하지 않도록 스크롤 영역에서 각 메시지 너비를 정한다.

응답 대기 중에는 작은 네이티브 불확정 진행 막대를 표시한다. 완료·오류·중지 시 숨기고 애니메이션을 멈춘다. 기존 안내 문구와 함께 실제 대기 상태를 보여주며 진행률 수치를 추정하지 않는다.

## 검증
- 전체 테스트 201개 통과.
- 대화 배치, 긴 메시지 줄바꿈, 실제 분할 창의 너비 조절·상한·재개방 유지 테스트 추가.
- 기존 CLI 직접 수정 통합 테스트에서 응답 대기·완료·취소 시 로딩 표시 상태 확인.
- 기존 문서 편집과 CLI 로그인 관련 변경을 보존하고 별도 경로에 앱을 빌드한다.
- 릴리스 빌드와 임시 서명 검증 완료: `.build/ai-chat-preview-NVyn0e/JenaNote.app`.
