# Pro 소스를 기존 패키지로 통합

사용자가 Pro 프로젝트를 더 이상 별도 사용하지 않기로 했다. 두 프로젝트는 같은 Swift Package 구조와 JenaNoteKit 모듈을 사용한다.

별도 하위 앱을 추가하는 대신 기존 모듈로 Pro 변경을 반영한다. 패키지·앱 식별자·배포 설정은 기존 값을 유지한다. 별도 Git 루트를 가진 이력을 강제 병합하는 방식은 채택하지 않는다. Pro 원본과 변경 전 파일 백업을 보존하여 출처 및 복구 가능성을 유지한다.

런타임 구조를 새로 설계하지 않으며 기존 NSDocument 기반 앱 구조를 유지한다. Pro의 커밋되지 않은 변경도 포함하므로 통합 이후 전체 테스트와 빌드를 확인한다.
