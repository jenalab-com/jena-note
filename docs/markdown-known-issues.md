# 마크다운 저장의 알려진 문제

`shared/JenaNoteCore/markdown`에서 아래 문제를 고쳤다. **Windows 앱에는 적용됐고, 맥 앱은 공유 코드로 전환할 때까지 그대로다.** 맥의 현재 동작은 `shared/TestSupport/MarkdownCorpus.swift`의 `macLegacy`에 항목별로 적혀 있다. 이 값은 코드를 읽어 적었고, 맥에서 `MarkdownCoreParityTests`로 확인한다. 2026-11-05에 Windows 앱에서 표 머리글, 코드 블록 언어, 표 뒤 빈 줄 문제를 실제로 보았다.

## 고친 문제

| 문제 | 입력 | 맥의 현재 저장 결과 | 공유 코드의 저장 결과 |
|---|---|---|---|
| 표 뒤 빈 줄이 저장마다 늘어난다 | 표, 빈 줄, 글 | 저장마다 빈 줄 1개 추가 | 그대로 |
| 표 바로 뒤 글에 빈 줄이 생긴다 | 표, 글 | 빈 줄 추가 | 그대로 |
| 표 머리글에 굵게 표시가 붙는다 | `\| A \|` | `\| **A** \|` | `\| A \|` |
| 표 안의 기울임과 굵게가 사라진다 | `\| *a* **b** \|` | `\| a b \|` | 그대로 |
| 표 열 정렬이 사라진다 | `\|:--\|` | `\| --- \|` | `\| :-- \|` |
| 셀 안의 `\|`가 셀을 나눈다 | `\| a\\|b \|` | 셀 2개 | 그대로 |
| 표 안의 글자 색이 기본 글자색으로 바뀐다 | 색을 지정한 셀 | 화면 모드의 글자색 | 그대로 |
| 파이프 한 글자 줄을 구분선으로 읽는다 | `a\|b`, `\|` | 표로 바뀐다 | 그대로 |
| 코드 블록 첫 줄이 비면 여는 펜스가 사라진다 | 빈 줄로 시작하는 코드 | 펜스 사라짐 | 그대로 |
| 코드 블록 끝 줄이 비면 닫는 펜스가 사라진다 | 빈 줄로 끝나는 코드 | 뒤의 글까지 코드가 된다 | 그대로 |
| 빈 코드 블록이 사라진다 | 내용 없는 코드 | 빈 줄 | 그대로 |
| 이웃한 코드 블록이 합쳐진다 | 코드 블록 2개 연속 | 1개 | 2개 |
| 코드 블록 언어가 사라진다 | ` ```swift ` | ` ``` ` | 그대로 |
| 안쪽에 펜스가 있는 코드 블록이 깨진다 | 백틱 4개 펜스 | 내용 일부만 남는다 | 그대로 |
| 한 줄 코드가 뒤 문서를 삼킨다 | ` ```a``` b ` | 문서 끝까지 코드 | `` `a` b `` |
| 백틱이 든 인라인 코드가 깨진다 | ``` `` a`b `` ``` | 백틱이 사라진다 | 그대로 |
| 단어 안의 밑줄이 기울임이 된다 | `snake_case_x` | `snake*case*x` | 그대로 |
| 빈 서식 기호가 사라진다 | `a****b` | `ab` | 그대로 |
| 이미지로 시작하는 제목이 본문이 된다 | `# ![a](b.png) 제목` | `#` 사라짐 | 그대로 |
| `<img>`의 다른 속성이 사라진다 | `<img src="a" height="9">` | `![](a)` | 그대로 |

## 그대로 둔 동작

내용이 사라지지 않고 표기만 통일되므로 유지했다.

| 동작 | 입력 | 저장 결과 |
|---|---|---|
| 목록 기호를 통일한다 | `* a`, `+ a` | `- a` |
| 구분선을 통일한다 | `***`, `___` | `---` |
| 밑줄 서식을 별표로 통일한다 | `__a__`, `_a_` | `**a**`, `*a*` |
| 표 구분선 간격을 통일한다 | `\|---\|` | `\| --- \|` |
| 굵은 제목과 표 머리글의 굵게 표시를 뺀다 | `# **a**` | `# a` |
| 문서 맨 앞 빈 줄과 맨 뒤 여러 빈 줄을 정리한다 | | |

이 프로젝트의 문서 89개로 시험한다(`RealDocumentsTests`). 두 번 저장해도 같고, 단어가 사라지지 않아야 한다. 코드 블록 밖에 붙여 넣은 `__NAME__` 같은 글자도 `**NAME**`이 되니, 로그는 코드 블록에 넣는다.

## 줄바꿈 (CRLF)

맥 앱은 줄을 `\n`으로만 나눈다. CRLF 파일을 열면 줄 끝의 `\r`이 본문에 남고 `---\r`은 구분선으로 인식되지 않는다. Windows 앱은 파일을 읽을 때 정규화한다.

## 전환할 때

맥 앱이 공유 코드로 전환하면 위 문제가 맥에서도 함께 고쳐진다. 그때 말뭉치의 `macLegacy`와 이 표의 맥 열을 지운다.
