| **항목** | **내용** |

# 2. PRD / 기능 명세

배경
macOS의 기본 메모앱(텍스트 에디트, Notes)은 서식을 `.md` 형식으로 저장하지 않는다. 마크다운 전용 에디터(Typora, Obsidian)는 기능이 과도하거나 플레인 마크다운 기호가 그대로 노출된다. JenaPad는 최소한의 인터페이스로 WYSIWYG 마크다운 편집 경험을 제공한다.

문제 정의
마크다운을 모르는 사용자도 서식 있는 문서를 `.md`로 저장해야 하는 상황이 있다. 기존 도구는 마크다운 기호가 화면에 그대로 보이거나(Raw 모드), `.md` 저장을 지원하지 않는다.

목표 / KPI
- 신규 사용자가 도움말 없이 3분 이내에 서식 있는 문서를 작성하고 저장할 수 있다
- 저장된 `.md` 파일을 다른 마크다운 뷰어에서 열었을 때 서식이 동일하게 렌더링된다
- 편집 중 마크다운 기호가 화면에 노출되지 않는다

대상 사용자 & 시나리오
| **사용자**** ****유형** | **시나리오** |
| --- | --- |
| 마크다운 비숙련자 | 회의 메모를 서식 있게 작성하고 팀에게 `.md`로 공유 |
| 마크다운 숙련자 | 빠르게 초안을 작성하고 기호 노출 없이 결과물 확인 |
| 개발자 | README 초안 작성, 외부 에디터에서 열어 수정 |

인스코프 (In-Scope)

- WYSIWYG 마크다운 편집기 (기호 숨김, 서식 적용 상태 표시)
- 툴바: 마크다운 서식 아이콘 (굵게, 기울임, 제목, 목록, 코드, 링크, 인용)
- 파일 메뉴: 새 문서, 열기, 저장, 다른 이름으로 저장, 닫기
- 편집 메뉴: 복사, 붙여넣기, 잘라내기, 실행 취소(Undo), 다시 실행(Redo), 전체 선택, 찾기
- Window / Help 메뉴: macOS 표준 구성
- `.md` 파일 저장 및 불러오기 (UTF-8)
- 문서 제목 = 파일명 연동 (창 제목 표시)
- 저장하지 않은 변경 사항 감지 → 닫기 전 경고

아웃오브스코프 (Out-of-Scope)
- 다중 탭 / 멀티 창 동시 편집
- 클라우드 동기화
- 이미지 삽입 / 첨부파일
- 플러그인 / 테마 커스터마이징
- iOS / iPadOS 지원
- 실시간 협업

비기능 요구사항
| **항목** | **기준** |
| --- | --- |
| 성능 | 10,000자 문서 입력 시 키 입력 반응 < 50ms |
| 호환성 | macOS 13 Ventura 이상 |
| 저장 포맷 | CommonMark 호환 `.md` (UTF-8) |
| 접근성 | VoiceOver 기본 지원, 키보드 완전 조작 가능 |

# 3. 사용자 플로우 (7단계 모델)

```
[1. 진입]
  앱 실행 → 빈 새 문서 화면 표시
  파인더에서 .md 파일 더블클릭 → 파일 열기
[2. 오리엔테이션]
  상단 툴바: 서식 아이콘 나열
  중앙: 편집 영역 (커서 대기)
  창 제목: 파일명 또는 "제목 없음"
[3. 작업]
  텍스트 입력
  툴바 아이콘 클릭 또는 단축키 → 서식 즉시 적용
  마크다운 기호는 보이지 않고 렌더링된 결과만 표시
[4. 검토]
  저장 전 현재 서식 상태 = 저장될 상태 (WYSIWYG이므로 별도 미리보기 불필요)
[5. 커밋]
  Cmd+S → 저장 (기존 파일: 덮어쓰기 / 새 문서: 저장 대화상자)
  Cmd+Shift+S → 다른 이름으로 저장
[6. 피드백]
  저장 성공: 창 제목 변경사항 표시 점(●) 제거
  저장 실패: 경고 시트 표시 (이유 명시)
[7. 재진입 / 복구]
  변경 사항 있는 상태에서 닫기 → "저장하시겠습니까?" 확인 시트
  저장 / 저장 안 함 / 취소 선택 가능
```

# 5. 인수 기준 (Acceptance Criteria)

AC-01: WYSIWYG 편집
```
시나리오 1 — 굵게 적용:
  Given 텍스트를 입력한 상태에서
  When 텍스트 선택 후 Cmd+B 또는 툴바 B 아이콘 클릭
  Then 선택 텍스트가 볼드체로 렌더링됨 (마크다운 ** 기호 미노출)
시나리오 2 — .md 파일 열기:
  Given .md 파일을 파인더에서 더블클릭 또는 파일 메뉴에서 열기
  When 파일 로드 완료
  Then 마크다운 기호 없이 서식 적용된 텍스트가 편집 영역에 표시됨
시나리오 3 — 저장 후 재오픈:
  Given 서식 있는 문서를 Cmd+S로 저장 후 파일 닫기
  When 저장된 .md 파일을 다시 열기
  Then 저장 전과 동일한 서식으로 표시됨
AC-02: 파일 저장
시나리오 1 — 새 문서 첫 저장:
  Given 새 문서에 텍스트 입력 후
  When Cmd+S
  Then 파일 저장 대화상자 표시, 파일명과 저장 위치 선택 가능
시나리오 2 — 기존 파일 저장:
  Given 이미 저장된 파일을 편집 중
  When Cmd+S
  Then 대화상자 없이 즉시 저장, 창 제목 변경 점 제거
시나리오 3 — 저장 실패 (권한 없음):
  Given 읽기 전용 경로의 파일
  When 저장 시도
  Then 오류 이유를 명시한 경고 시트 표시 ("파일에 쓰기 권한이 없습니다.")
AC-03: 미저장 경고
시나리오 1 — 변경 사항 있는 상태에서 닫기:
  Given 편집 후 저장하지 않은 상태에서
  When 창 닫기 버튼 클릭 또는 Cmd+W
  Then "저장하시겠습니까?" 확인 시트 표시
시나리오 2 — 변경 사항 없는 상태에서 닫기:
  Given 마지막 저장 이후 변경 없음
  When 창 닫기
  Then 경고 없이 즉시 닫힘
```

# 6. 데이터 / 저장 포맷
- 저장 포맷: UTF-8 인코딩 CommonMark 호환 `.md`
- 내부 표현: NSAttributedString ↔ Markdown 변환 (저장 시 직렬화, 열기 시 역직렬화)
- Undo/Redo 스택: NSUndoManager (시스템 기본)
- 파일 상태 감지: `NSDocument` 또는 직접 변경 추적 (`isEdited` 플래그)
---

```

[ ] 표준 macOS 단축키 (Cmd+S, Cmd+Z, Cmd+C/V/X) 모두 동작
```
