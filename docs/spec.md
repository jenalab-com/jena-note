# 2. PRD / 기능 명세

배경
macOS의 기본 메모앱(텍스트 에디트, Notes)은 서식을 `.md` 형식으로 저장하지 않는다. 마크다운 전용 에디터(Typora, Obsidian)는 기능이 과도하거나 플레인 마크다운 기호가 그대로 노출된다. JenaPad는 최소한의 인터페이스로 WYSIWYG 마크다운 편집 경험을 제공한다.

문제 정의
마크다운을 모르는 사용자도 서식 있는 문서를 `.md`로 저장해야 하는 상황이 있다. 기존 도구는 마크다운 기호가 화면에 그대로 보이거나(Raw 모드), `.md` 저장을 지원하지 않는다.

목표 / KPI
- 신규 사용자가 도움말 없이 3분 이내에 서식 있는 문서를 작성하고 저장할 수 있다
- 저장된 `.md` 파일을 다른 마크다운 뷰어에서 열었을 때 서식이 동일하게 렌더링된다
- 편집 중 마크다운 기호가 화면에 노출되지 않는다

대상 사용자 & 시나리오
| **사용자**** ****유형** | **시나리오** |
| --- | --- |
| 마크다운 비숙련자 | 회의 메모를 서식 있게 작성하고 팀에게 `.md`로 공유 |
| 마크다운 숙련자 | 빠르게 초안을 작성하고 기호 노출 없이 결과물 확인 |
| 개발자 | README 초안 작성, 외부 에디터에서 열어 수정 |

인스코프 (In-Scope)

- WYSIWYG 마크다운 편집기 (기호 숨김, 서식 적용 상태 표시)
- 툴바: 마크다운 서식 아이콘 (굵게, 기울임, 제목, 목록, 코드, 링크, 인용)
- 파일 메뉴: 새 문서, 열기, 저장, 다른 이름으로 저장, 닫기, **폴더 추가…**
- 편집 메뉴: 복사, 붙여넣기, 잘라내기, 실행 취소(Undo), 다시 실행(Redo), 전체 선택, 찾기
- **보기 메뉴: 사이드바 표시/숨기기 (⌘⌥S)**
- Window / Help 메뉴: macOS 표준 구성
- `.md` 파일 저장 및 불러오기 (UTF-8)
- 문서 제목 = 파일명 연동 (창 제목 표시)
- 저장하지 않은 변경 사항 감지 → 닫기 전 경고
- **좌측 사이드바 — 사용자 등록 폴더의 `.md` 파일 트리 (재귀), 클릭 시 인-플레이스 문서 교체, FSEvents 기반 실시간 갱신, 폴더 추가·제거, 등록 폴더 영속 (자세한 명세는 §3'/SCREEN-03/AC-04~AC-08 참조)**
- **검색 — 문서 내 검색(⌘F, 네이티브 찾기 바 + 위/아래 이동 + 매치 카운트), 찾아 바꾸기(⌥⌘F), 파일 전체 검색(⇧⌘F, 사이드바 통합 — SCREEN-05/AC-09/AC-10 참조)**
- **이어읽기 — 읽기 모드에서 읽던 위치를 문서별로 자동 기억·복원. 표시 설정(폰트·행간·폭·페이지 모드)이 바뀌어도 유지 (AC-11 참조)**
- **책갈피 — 읽기 모드에서 ⌘D로 현재 위치 표시/해제, 툴바 팝오버로 목록·점프·삭제 (AC-12 참조)**

아웃오브스코프 (Out-of-Scope)
- 다중 탭 / 멀티 창 동시 편집
- 클라우드 동기화
- 이미지 삽입 / 첨부파일
- 플러그인 / 테마 커스터마이징
- iOS / iPadOS 지원
- 실시간 협업

비기능 요구사항

# 3. 사용자 플로우 (7단계 모델)

```
[1. 진입]
  앱 실행 → 빈 새 문서 화면 표시
  파인더에서 .md 파일 더블클릭 → 파일 열기
[2. 오리엔테이션]
  상단 툴바: 서식 아이콘 나열
  중앙: 편집 영역 (커서 대기)
  창 제목: 파일명 또는 "제목 없음"
[3. 작업]
  텍스트 입력
  툴바 아이콘 클릭 또는 단축키 → 서식 즉시 적용
  마크다운 기호는 보이지 않고 렌더링된 결과만 표시
[4. 검토]
  저장 전 현재 서식 상태 = 저장될 상태 (WYSIWYG이므로 별도 미리보기 불필요)
[5. 커밋]
  Cmd+S → 저장 (기존 파일: 덮어쓰기 / 새 문서: 저장 대화상자)
  Cmd+Shift+S → 다른 이름으로 저장
[6. 피드백]
  저장 성공: 창 제목 변경사항 표시 점(●) 제거
  저장 실패: 경고 시트 표시 (이유 명시)
[7. 재진입 / 복구]
  변경 사항 있는 상태에서 닫기 → "저장하시겠습니까?" 확인 시트
  저장 / 저장 안 함 / 취소 선택 가능
```

# 5. 인수 기준 (Acceptance Criteria)

AC-01: WYSIWYG 편집
```
시나리오 1 — 굵게 적용:
  Given 텍스트를 입력한 상태에서
  When 텍스트 선택 후 Cmd+B 또는 툴바 B 아이콘 클릭
  Then 선택 텍스트가 볼드체로 렌더링됨 (마크다운 ** 기호 미노출)
시나리오 2 — .md 파일 열기:
  Given .md 파일을 파인더에서 더블클릭 또는 파일 메뉴에서 열기
  When 파일 로드 완료
  Then 마크다운 기호 없이 서식 적용된 텍스트가 편집 영역에 표시됨
시나리오 3 — 저장 후 재오픈:
  Given 서식 있는 문서를 Cmd+S로 저장 후 파일 닫기
  When 저장된 .md 파일을 다시 열기
  Then 저장 전과 동일한 서식으로 표시됨
AC-02: 파일 저장
시나리오 1 — 새 문서 첫 저장:
  Given 새 문서에 텍스트 입력 후
  When Cmd+S
  Then 파일 저장 대화상자 표시, 파일명과 저장 위치 선택 가능
시나리오 2 — 기존 파일 저장:
  Given 이미 저장된 파일을 편집 중
  When Cmd+S
  Then 대화상자 없이 즉시 저장, 창 제목 변경 점 제거
시나리오 3 — 저장 실패 (권한 없음):
  Given 읽기 전용 경로의 파일
  When 저장 시도
  Then 오류 이유를 명시한 경고 시트 표시 ("파일에 쓰기 권한이 없습니다.")
AC-03: 미저장 경고
시나리오 1 — 변경 사항 있는 상태에서 닫기:
  Given 편집 후 저장하지 않은 상태에서
  When 창 닫기 버튼 클릭 또는 Cmd+W
  Then "저장하시겠습니까?" 확인 시트 표시
시나리오 2 — 변경 사항 없는 상태에서 닫기:
  Given 마지막 저장 이후 변경 없음
  When 창 닫기
  Then 경고 없이 즉시 닫힘
```

# 6. 데이터 / 저장 포맷
- 저장 포맷: UTF-8 인코딩 CommonMark 호환 `.md`
- 내부 표현: NSAttributedString ↔ Markdown 변환 (저장 시 직렬화, 열기 시 역직렬화)
- Undo/Redo 스택: NSUndoManager (시스템 기본)
- 파일 상태 감지: `NSDocument` 또는 직접 변경 추적 (`isEdited` 플래그)

# 8. 사이드바 폴더 브라우저 (추가)

기획 로그: `docs/planning-log/2026-05-17-sidebar-folder-browser.md`

## 8.1 사용자 플로우 추가 분기

```
[3'. 작업 — 폴더 추가]
  사이드바 헤더 "+" 클릭 또는 파일 > 폴더 추가… (⇧⌘O)
  → NSOpenPanel(canChooseFiles=false, canChooseDirectories=true)
  → 사용자가 폴더 선택 → 사이드바 루트로 추가, 펼침
  → FSEvents 구독 시작

[3''. 작업 — 파일 열기 via 사이드바]
  사이드바에서 .md 파일 클릭
  → 현재 문서가 unmodified: 현재 창에서 문서 교체 (in-place swap)
  → 현재 문서에 미저장 변경 존재: 저장 확인 시트(저장/저장 안 함/취소)
    · 저장: 저장 후 교체  · 저장 안 함: 즉시 교체  · 취소: 사이드바 선택 복원
  → 클릭한 파일이 이미 다른 창에 열려 있으면 그 창을 전면으로

[6'. 피드백 — 외부 변경]
  외부에서 파일/폴더 추가·삭제·이름변경 → 사이드바 트리 자동 갱신 (p95 ≤ 1초)
  외부에서 현재 편집 중인 파일 삭제 → 편집기 상단 비-모달 알림: "이 파일이 외부에서 삭제되었습니다." [다른 이름으로 저장] [닫기]
  등록 폴더가 디스크에서 사라짐/이동 → 트리 루트에 ⚠ + [Locate…] [Remove]
```

## 8.2 SCREEN-03: 사이드바

| 항목 | 내용 |
| --- | --- |
| 목적 | 등록 폴더와 `.md` 파일을 탐색하고 즉시 열기 |
| 진입 조건 | 앱 실행 시 기본 표시 (보기 메뉴로 토글) |
| 주요 콘텐츠 | 헤더(타이틀 + "+" 버튼), 트리(NSOutlineView), 빈 상태 CTA |
| 기본 CTA | "폴더 추가…" |
| 보조 액션 | 행 클릭(열기), 디스클로저(펼침/접기), 우클릭(Remove / Reveal in Finder) |

**상태 정의 (필수)**

| 상태 | 조건 | 표현 |
| --- | --- | --- |
| 기본 | 폴더 ≥ 1, 정상 접근 | 트리 정상 표시 |
| 비어있음 | 등록 폴더 0개 | placeholder + [폴더 추가…] 버튼 |
| 로딩 | 200ms 이상 첫 스캔 | 노드 옆 spinner |
| 권한 거부 | 읽기 권한 없음 | 루트에 🔒 + 툴팁 안내 |
| 폴더 누락 | 디스크에서 사라짐 | 루트에 ⚠ + [Locate…] [Remove] |
| 오프라인 | 외부 볼륨 분리 | 폴더 누락과 동일 (Reconnect 대체) |

# 10. 이어읽기·책갈피 (ADR-0008)

이어읽기는 별도 화면 없이 읽기 모드(SCREEN-01 우측 페인) 안에서 조용히 동작한다. 사용자가 조작할 UI는 없다.
책갈피는 리더 툴바에 아이콘 2개(표시 토글·목록)를 두고, 목록은 팝오버로 띄운다.

## 10.1 인수 기준 (AC-11)

```
AC-11: 읽던 위치 자동 기억·복원
시나리오 1 — 같은 문서 재진입:
  Given 읽기 모드에서 문서 중간까지 읽다가 읽기 모드를 나감
  When 같은 문서에서 다시 읽기 모드 진입
  Then 마지막으로 보던 위치가 화면에 복원됨
시나리오 2 — 표시 설정 변경:
  Given 읽기 모드에서 문서 중간을 보는 중
  When 폰트 크기·서체·행간·단 폭·페이지 모드를 바꿈
  Then 조판이 다시 잡히더라도 보고 있던 문장이 화면에 남음
시나리오 3 — 문서 전환:
  Given 읽기 모드에서 A 문서를 읽던 중
  When 사이드바로 B 문서를 열고 다시 A 문서로 돌아옴
  Then A 는 읽던 위치, B 는 B 자신의 위치로 각각 복원됨
시나리오 4 — 문서가 편집된 경우:
  Given 위치를 기억한 뒤 그 문서 앞부분이 편집되어 오프셋이 밀림
  When 다시 읽기 모드 진입
  Then 문맥 스니펫으로 재동기화해 읽던 문장을 다시 찾아냄
시나리오 5 — 앱 종료:
  Given 읽기 모드로 문서를 읽는 중
  When 앱을 종료하고 다시 실행해 같은 문서를 읽기 모드로 엶
  Then 읽던 위치가 복원됨
시나리오 6 — 맨 앞:
  Given 문서를 맨 앞에서만 보다가 나감
  When 다시 진입
  Then 맨 앞에서 시작 (복원할 것이 없으므로 저장도 남기지 않음)
```

## 10.2 SCREEN-06: 책갈피 팝오버

```
리더 툴바 우측: [🔖 표시/해제] [☰ 목록]

목록 팝오버 (툴바 아이콘 아래, 폭 320):
┌──────────────────────────────┐
│ “두 번째 문단입니다. 읽던…”   │   ← 문서 순서(오프셋 오름차순)
│ “세 번째 문단입니다. 이야…”   │   ← 클릭: 그 자리로 점프 + 팝오버 닫힘
│ “네 번째 문단입니다. 여기…”   │   ← 선택 후 ⌫: 삭제
└──────────────────────────────┘

비어 있을 때: 가운데에 “책갈피 없음”
높이: 항목 수에 맞춰 늘되 12줄에서 멈추고 스크롤
```

| 요소 | 동작 |
|---|---|
| 🔖 아이콘 | 현재 화면에 책갈피 있으면 `bookmark.fill`, 없으면 `bookmark` |
| ⌘D | 현재 화면에 책갈피 있으면 해제, 없으면 현재 위치에 추가 |
| 목록 항목 문구 | 저장값이 아니라 현재 본문에서 매번 추출 (편집돼도 실제 문장과 일치) |
| 저장 안 된 새 문서 | 메뉴·단축키 비활성 (매어 둘 파일 경로가 없음) |

## 10.3 인수 기준 (AC-12)

```
AC-12: 책갈피
시나리오 1 — 표시:
  Given 읽기 모드에서 특정 위치를 보는 중
  When ⌘D 또는 툴바 🔖 클릭

시나리오 2 — 해제:
  Given 현재 화면에 책갈피가 있는 상태
  When 다시 ⌘D
  Then 그 책갈피가 사라지고 아이콘이 빈 모양으로 돌아감
시나리오 3 — 목록·점프:
  Given 책갈피가 여러 개인 문서
  When 툴바 ☰ 클릭
  Then 문서 순서대로 미리보기 문구가 나열되고, 항목 클릭 시 그 자리로 이동
시나리오 4 — 삭제:

시나리오 5 — 문서별 분리:

  When 목록을 열어 항목 클릭
  Then 문맥 스니펫으로 재동기화된 위치로 이동, 목록 문구도 현재 본문 기준
```
