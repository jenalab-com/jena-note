# 초기 작품 파악의 외부 AI 사용량 제거

문제: 자동 인덱싱이 집필용 CLI 한도를 소비한다. 사용자 요청으로 기기 내 요약을 채택한다.
대안: CLI 유지/자동 우회, 사용 불가 시 차단, 로컬 요약+발췌를 비교했다.
결정: Foundation Models로 초기·증분 요약, 비지원/실패 조각은 원문 발췌로 검색 유지. 외부 AI 자동 우회 없음.
이유: 작가의 수동 관리와 준비 비용을 줄이며 비지원 기기에서도 원고 작업을 지속한다.
트레이드오프: 작은 조각으로 호출 수가 늘고 발췌는 요약보다 검색 단서가 약하다. 실제 질문은 원문을 다시 확인한다.
보류: 대규모 한국어 작품 품질/시간 비교, 벡터 검색, 구형 OS 실기 검증.
