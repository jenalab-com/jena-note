# CLI 기반 AI 모드

## 문제와 선택
글을 읽고 쓰는 자리에서 현재 문서와 선택 부분을 AI에 전달하고, 가이드 또는 직접 수정을 받을 수 있어야 한다. 사용자는 API 키 대신 로컬에 설치·로그인한 Claude Code, Codex, Gemini CLI, Grok CLI를 사용하는 방향을 승인했다. CLI가 없으면 설치 실행과 안내를 제공하고 로그인 후 재확인할 수 있어야 한다.

## 가정
- 기존 macOS AppKit 앱 구조와 문서·Undo 시스템을 유지한다.
- Grok은 사용자 Stop 훅 충돌을 피하기 위해 JenaNote 전용 프로필에서 별도로 로그인한다. 다른 제공사는 기존 CLI 로그인을 사용한다.
- 인증과 모델 사용 권한은 각 공식 CLI가 관리한다. JenaNote는 인증 파일을 읽거나 복제하지 않는다.
- 현재 페이지는 현재 열린 문서의 본문으로 해석한다. 선택이 있으면 수정 대상은 선택 범위이다.
- 대화는 앱 실행 중 파일별로 유지한다. 앱 재시작 후 대화 복원은 이번 범위에 포함하지 않는다.
- 공식 CLI 최신판의 OS/런타임 조건은 JenaNote 자체 요구사항과 다를 수 있다.

## 흐름
1. 상단 AI 버튼 → 우측 채팅. 페이지 조판은 일시 중지하고 스크롤 편집기로 전환한다.
2. 설정 → 제공사 선택, 자동 탐색 또는 실행 파일 직접 선택.
3. 미설치 → 설치 버튼 → Terminal에서 공식 설치 명령 실행. Gemini는 기존 npm/Homebrew 사용; 없다면 설치 안내.
4. 로그인 버튼 → Terminal에서 CLI 로그인. 완료 후 재확인 → 버전 검사와 짧은 실제 AI 요청.
5. 가이드/직접 수정 선택 → 현재 본문·선택·해당 문서 대화 전달 → 응답 표시 및 검증된 변경 적용.
6. 다른 파일로 전환/AI 창 닫기/윈도우 닫기 → 해당 요청 취소, 다른 문서에 적용하지 않음.

## 인수 조건
- 설치·로그인·연결 상태를 혼동하지 않고, 재확인의 소량 사용량 발생을 알린다.
- AI 창이 열린 동안 페이지 보기로 전환되지 않으며 닫으면 원래 설정이 유지된다.
- 파일 A의 대화와 초안은 B에 섞이지 않고 A로 돌아오면 복원된다.
- 선택 영역 밖의 본문과 남아 있는 서식은 보존한다. AI 적용은 한 번의 문서 Undo로 복원된다.
- 본문 또는 서식이 응답 대기 중 바뀌면 수정은 적용하지 않고 결과를 채팅에 남긴다.
- 중지·시간 초과는 CLI 하위 프로세스가 파이프를 유지하더라도 종료된다.
- 자동 테스트는 실제 계정 호출 없이 CLI 응답 fixture로 성공·실패·문서 수정 흐름을 검증한다.

## 범위와 보류
- 설치는 사용자가 설정의 설치 버튼을 누르면 실행한다. 앱 시작만으로 도구를 설치하거나 기존 CLI를 덮어쓰지 않는다.
- 본문/대화 500 KB 초과 요청은 자동 생략하지 않고 오류로 알린다.
- 스트리밍 토큰 UI, 대화의 디스크 저장, 모델 선택 UI, 이미지 내용 이해는 후속 범위다.
- 직접 수정은 텍스트 수정이다. 이미지가 제거되는 변경은 자동 적용하지 않는다.
