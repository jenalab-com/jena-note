**1. 맞춤법 및 문법 검사 (**`F8` **/ 실시간 밑줄)**

- **맞춤법 검사기 (한글의** `F8` **등):** 띄어쓰기, 오탈자, 잘못 쓰인 단어를 자동으로 찾아주고 바른 표현으로 고치도록 돕습니다.
- **비문 및 오타 표시:** 작성 도중 붉은색이나 파란색 밑줄로 어색한 문장이나 오타를 실시간 확인합니다. \[[1](https://blog.naver.com/sntu2010/221536512931), [2](https://arca.live/b/webfiction/34138951)\]

**2. 실시간 글자수 및 분량 체크**

- **상태 표시줄 글자수 확인:** 화면 하단(또는 문서 정보)에서 공백 포함/제외 글자수, 원고지 매수, 단어 수를 실시간으로 확인하며 분량을 조절합니다. [[1](https://www.youtube.com/watch?v=8uGa7D6va3s&t=161), [2](https://arca.live/b/webfiction/34138951)]

**3. 찾기 및 바꾸기 (**`Ctrl + H`**)**

- **일괄 수정 (**`Ctrl + H`**):** 특정 인물의 이름이 바뀌었거나 자주 틀리는 단어, 오탈자를 문서 전체에서 한 번에 찾아 다른 단어로 바꿉니다. [[1](https://blog.naver.com/hubis7777/223425509588), [2](https://arca.live/b/webfiction/34138951)]

**4. 자동 저장 및 백업 기능**

- **파일 유실 방지:** 정해진 주기로 원고를 자동 저장하거나 임시 백업본을 생성하여 정전이나 프로그램 오류로 인한 글 날림 사고를 방지합니다. [[1](https://arca.live/b/webfiction/34138951)]

**5. 화면 환경 설정 (눈 피로 감소)**

- **배경색 및 시력 보호 모드:** 장시간 모니터를 보며 집필하기 때문에 눈이 피로하지 않도록 페이지 배경색을 은은한 녹색이나 회색 등으로 변경해 사용합니다. [[1](https://arca.live/b/webfiction/34138951), [2](https://blog.naver.com/sntu2010/221536512931)]

**6. 각주 및 미주 삽입 (**`Ctrl + Alt + F` **/** `Ctrl + Alt + D`**)**

- **참조 및 주석 처리:** 소설이나 에세이, 논픽션 집필 시 추가 설명이나 출처를 표기하기 위해 페이지 하단(`Ctrl + Alt + F`)이나 문서 맨 끝(`Ctrl + Alt + D`)에 각주와 미주를 넣습니다. [[1](https://blog.naver.com/hubis7777/223425509588)]

**7. 변경 내용 추적 및 검토 기능 (워드)**

- **편집자·출판사와의 협업:** [**++Microsoft Word++**](https://www.microsoft.com/ko-kr/microsoft-365/word)의 '변경 내용 추적(Track Changes)' 기능을 활용해 출판사 편집자와 원고를 주고받으며 수정 사항을 기록하고 피드백을 주고받습니다. \[[1](https://nothingcat.tistory.com/580)\]
