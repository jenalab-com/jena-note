# 선택 문장 기기 내 교정

## 목적과 범위

작가가 선택한 짧은 문장의 맞춤법·띄어쓰기 교정안을 확인하고 직접 적용한다. 기존 AppKit의 중립적인 원문/제안 비교 화면을 사용한다. 자동 검사·자동 적용·전체 원고 검사·설치 앱 교체는 이번 범위가 아니다.

## 동작

- 상단 `선택 문장 검사`와 편집 메뉴에서 실행. 선택이 없거나 원문 보기 중이면 비활성화한다. 스크롤·페이지 보기 모두 문서 좌표의 선택 영역을 사용한다.
- 최대 500자 및 1,500 UTF-8바이트를 허용한다. 초과하면 짧게 선택하도록 안내하며 임의로 잘라 검사하지 않는다. 이미지/각주 등 첨부 문자와 한글 조합 중인 영역은 검사하지 않는다.
- Foundation Models의 온디바이스 모델에 원문만 전달한다. 별도 CLI·네트워크 서비스로 우회하지 않는다. macOS 26 미만, 모델 준비 안 됨, 지원 언어가 아닌 경우 이유를 표시한다.
- 지시는 맞춤법·띄어쓰기에 한정하고 이름·문체·의미·줄바꿈 보존을 요구한다. 구조화 응답의 교정문을 표시한다. 구조화 출력이 교정 정확도를 보장하지는 않는다.
- 원문과 교정 제안을 읽기 전용으로 비교한다. 결과가 같으면 변경 제안 없음으로 표시한다. `적용`은 결과가 있고 원문과 다를 때만 활성화한다.
- 적용 전에 문서 식별자·원문 스냅샷·한글 조합 여부를 재검증한다. 기존 `AIEditSnapshot.replacement`와 문서 소유 undo를 재사용하여 선택 밖 내용과 남은 서식을 보존한다. 적용은 한 번의 실행 취소로 복구한다.
- 창 닫기·문서 전환·취소 시 요청을 취소하고 늦은 결과를 무시한다.

## 기기 내 작업 순서

요약과 교정은 공용 직렬 실행기를 사용한다. 대기열에서 교정을 먼저 선택하지만 현재 실행 중인 요약을 임의로 취소하지 않는다. 교정은 대기 시간을 포함해 30초 제한을 둔다. 시간 초과는 UI에 즉시 전달하고 추론 취소를 요청한다. SDK가 취소에 늦게 응답하면 기존 실행이 끝날 때까지 다음 추론을 시작하지 않아 동시 실행을 피한다. 요약은 기존 120초 실행 제한을 유지한다.

## 검증

- 가짜 모델로 선택 길이·지원 불가·오류·시간 초과·취소·우선순위·최대 동시 실행 1을 검증한다.
- 실제 편집기에서 원문/선택 밖 보존, 교정안 승인 적용, 한 번의 undo, 서식·Unicode·변경 충돌을 검사한다.
- 실제 기기 내 모델에 직접 만든 예문으로 교정 결과와 지연을 측정한다. 사용자 원고는 실험에 사용하지 않는다.
- 전체 테스트 및 릴리스 빌드로 기존 요약 기능의 회귀를 확인한다. 실제 교정 품질이 부족하면 한계를 그대로 보고한다.
