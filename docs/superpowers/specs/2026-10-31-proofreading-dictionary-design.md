# 교정 후보 팝오버와 내 사전

## 요구와 가정
선택 검사 시트를 열지 않고 후보를 확인·적용하며, 허용할 표현은 다시 표시하지 않는다. 단일 사용자 로컬 앱이고 여러 작품을 편집한다. 사용자가 등록 기본 범위를 현재 작품으로 선택했다. 원문·서식·Undo·한글 조합 보호를 유지한다.

## 선택한 설계
- 마우스 오버 또는 본문 커서/선택이 후보에 들어오면 작은 팝오버로 원문/수정안, 적용, 사전 담기를 제공한다. 편집 중인 커서를 빼앗지 않으며 원문 변경·페이지 이동·창 닫기 때 오래된 제안을 폐기한다.
- 적용은 해당 후보의 어절/구절 범위만 기존 AIEditSnapshot 검증과 Undo 경계로 교체한다. 다른 후보를 함께 바꾸지 않는다.
- 등록은 원문의 표현을 미리 채우고 적용 범위를 확인한 뒤 저장한다. 기본은 현재 작품, 작품 밖 문서는 전체 작품을 명시한다. 여러 작품을 지정하거나 전체 범위로 변경할 수 있다.
- Application Support의 하나의 사전에 항목별 적용 범위를 둔다. 전체 또는 작품 UUID 집합이다. 작품 UUID는 로컬 사전의 작품 목록에 저장하며 폴더 북마크로 이동을 추적한다. 작품명은 표시용이고 동명이작은 폴더 경로로 구분한다. 기존 작품 설정 파일에 ID를 강제로 쓰지 않는다.
- Kiwi → 최소 수정 후보 → 현재 범위의 사전 필터 → 표시 순서. 정확히 등록한 표현 범위에 포함되는 수정만 제외한다. 문장 전체나 부분 문자열이 우연히 포함된 다른 단어는 제외하지 않는다. 제한된 조사 접미는 허용하되 일반 활용형 추론은 하지 않는다.
- 원본 Kiwi 결과를 캐시하고 사전 필터는 그 뒤에 적용한다. 사전 변경 알림으로 열린 문서를 다시 표시하며 선택 검사에도 같은 필터를 적용한다.
- 편집 > 내 사전 메뉴에서 검색, 등록, 표현·범위 수정, 활성/비활성화를 제공한다. 비활성화로 오류 검사 제외를 해제한다. 자동 삭제는 없다. 저장은 원자적으로 수행하고 기존 파일은 변경 전 보관한다. 파일 손상 시 원본을 덮어쓰지 않는다.

## 대안과 트레이드오프
- 작품별 파일: 격리는 쉽지만 공유·수정 시 중복과 버전 불일치가 생긴다.
- 완전 공통 사전: 구현은 단순하지만 특정 작품의 비표준 표현이 다른 작품의 정상 오류 검출을 가린다.
- 작품명 태그만: 보기에는 간편하지만 이름 변경/동명이작/태그가 없는 항목의 의미가 모호하다.
- 단일 저장소와 명시적 적용 범위: 관리 화면과 작품 식별이 조금 복잡하지만 중복 없이 선택적 공유가 가능하다. 이름 태그 대신 UUID 집합을 실제 판정에 쓴다.

## 수용 기준
후보 위치에서 별도 선택 검사 없이 수정안을 확인하고 명시적으로 적용할 수 있다. 적용 후 한 번의 Undo로 복원된다. 사전 저장 후 해당 범위의 후보만 사라지고 다른 작품/같은 문장의 다른 오류는 남는다. 전역 항목은 작품 밖에서도 적용된다. 재시작 후 유지되고, 손상/저장 실패 시 기존 데이터를 보존한다. 사용자 사전은 맞춤법 정답 사전이나 Kiwi 재학습 데이터가 아닌 검사 예외 목록이다.
