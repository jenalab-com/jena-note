# 작품 자동 인덱싱과 요청별 자료 탐색

> 초기 요약 제공사·분할·비용 정책은 `2026-10-28-foundation-work-index-design.md`와 ADR-0016으로 대체됨. 이 문서의 CLI 초기 요약은 이전 결정 이력이다.

상태: 구현 기준 · 2026-10-28

## 문제와 목표
작가가 설정 파일을 제외하거나 요약해서 500KB를 맞추는 작업을 없앤다. 작품 폴더와 참고 자료만 등록하면 앱이 최초 정리하고, 세션과 문서가 바뀌어도 재사용한다. 같은 내용 재개방 시 AI 인덱싱 호출 0회, 변경 시 바뀐 조각만 호출, 모든 최종 프롬프트 500,000바이트 이하를 검증한다.

## 가정과 범위
로컬 macOS 앱, 한 작품 수십~수백 화, 기존 4종 CLI의 텍스트 입출력을 사용한다. CLI별 새 도구 API에 의존하지 않는다. 등록된 작품의 자동 준비는 사용자가 요청한 제품 동작이며 AI 사용량이 발생한다. 편집은 준비 중에도 가능하다. 미등록 문서는 자동으로 등록하거나 전송하지 않는다.

## 사용자 흐름과 화면
등록 → 글 열기 → 상태바에 ‘작품을 파악하고 있어요 · N/M’ → 완료 후 자동 참고.
같은 작품 재개방은 캐시 재사용. 저장 후 변경은 잠시 모아 갱신하고 요청 직전에도 디스크를 재검사한다. AI가 없거나 실패하면 오류와 재시도 동작을 제공하고 완료된 조각은 보존한다. 인덱싱은 작품 공유 작업으로 문서 전환에 취소하지 않는다. 사용 중지 시 멈춘다.
참고 자료 탭은 등록·제거와 파일 목록 중심. 기본 자동 모드에서는 용량 막대와 원문/요약 수동 조절을 감춘다. 지난 화 탭은 자동 준비 상태와 재시도 중심. 기존 수동 요약 파일은 삭제하지 않는다.

## 저장과 갱신
`.jenanote/work-index.json`에 버전, 파일 상대 경로, 종류, 해시, 조각별 줄 범위·검색용 요약을 원자적으로 저장한다. 원문을 줄 범위가 있는 제한 크기 조각으로 나눠 큰 설정 파일도 처리한다. 내용·종류가 같은 조각의 요약은 재사용한다. 삭제·이름 변경·참고 출처 변경은 재스캔 결과가 기준이다. 중단 시 조각별 저장으로 재개한다. 손상 캐시는 다시 구축한다. 기존 직접 수정 요약은 보존하며 새로운 인덱스와 분리한다.

## 요청별 탐색
열린 글의 미저장 스냅샷과 질문, 접근 가능한 자료 목차를 AI에 보낸다. AI는 JSON으로 검색어·조각 ID·목차 페이지를 요청한다. 앱이 등록 자료와 현재 화 이전으로 제한하여 검색·발췌한다. 일반 셸 권한은 열지 않는다. 원문 검색은 대소문자 무시 문자열 검색이며 결과와 읽기 크기를 제한한다. 최대 4회 탐색 후 근거와 함께 기존 가이드/수정 호출을 실행한다.
설정 요약은 탐색 안내이며 확정 근거가 아니다. 판단에 쓰는 조각은 원문으로 읽게 한다. 공통 설정 요약을 작은 기본 문맥으로 제공하고 누락 범위를 명시한다. 전체 폴더를 미리 정리해도 현재 화 이후의 목차·요약·원문은 요청에 포함하지 않는다. 미저장 현재 글은 요청 스냅샷, 열린 설정은 현재 편집 내용을 반영한다.

## 예산과 실패
500KB는 UTF-8 프롬프트 한도이지 토큰 한도가 아니다. 탐색은 횟수·출력·문맥 크기·시간을 각각 제한한다. 최종 문맥은 자동으로 줄이고 확인하지 못한 범위를 표시한다. 본문 자체가 한도를 넘으면 명확한 오류를 표시하며 임의로 본문을 자르지 않는다. 자동 선택은 완전한 설정 검증을 보장하지 않는다. 준비 실패는 답변을 중단하고 질문을 보존한다. 취소된 답변과 문서 전환 후 응답은 적용하지 않는다.

## 검증 기준
- 재개방·새 서비스 인스턴스에서도 동일 내용의 요약 호출 0회.
- 큰 파일 분할, 한 파일 수정, 삭제, 추가, 취소·실패 후 재개.
- 같은 작품 동시 준비 중복 생성 방지.
- 미래 화·미등록 자료·심볼릭 링크 접근 차단.
- 검색 후 원문 발췌, 잘못된 ID/JSON, 탐색 제한, 예산 초과.
- 가이드·수정·취소·편집 충돌·기존 일반 문서 회귀.

## 대안과 유보
CLI 셸 직접 개방은 제공사별 권한 차이 때문에 선택하지 않는다. 벡터 DB는 로컬 조각 검색으로 먼저 검증하며 유보한다. 자동 요약은 비용과 초기 지연을 수반한다. 실제 CLI 품질·대규모 작품 속도와 화면 육안 검증은 자동 테스트와 별도로 기록한다.
