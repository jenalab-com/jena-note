# 배경색·백업·문서 끝 주석

## 목표와 가정
작가가 오래 읽기 편한 화면을 고르고, 이전 원고를 되찾고, 본문을 끊지 않고 설명을 붙인다. 로컬 단일 사용자 앱이며 Markdown 원본이 권위 데이터다. 기존 저장/Undo/페이지 조판을 유지한다. 원고 폴더의 별도 이미지 파일은 텍스트 백업 대상이 아니다.

## 결정
- 배경색: 기본/세피아/연녹색/회색. 전역 보기 설정으로 저장하고 스크롤·페이지·소스 보기의 바탕에 적용한다. 각 프리셋은 라이트/다크에 맞는 색을 가진다. 본문 속성·파일·내보내기에 색을 쓰지 않는다.
- 백업: Application Support/JenaNote/Backups 아래 문서 경로 해시별로 저장한다. 원고 폴더나 AI 검색에는 섞이지 않는다. 변경된 저장본을 보관하고 자동 저장은 5분 간격, 수동 저장은 즉시 기록한다. 문서당 최근 100개 유지. 최초 덮어쓰기 전 디스크 원본도 보존한다. 백업 실패는 원고 저장을 막지 않되 오류를 알린다.
- 복원: 파일 메뉴에서 날짜별 목록과 텍스트 미리보기를 제공한다. 복원 직전 미저장 원고도 백업해야 하며 실패하면 복원을 중단한다. 선택한 내용을 현재 문서의 Undo 가능한 편집으로 적용한다. 즉시 디스크를 덮어쓰지 않는다. 새 문서는 먼저 저장 안내. 백업은 이 Mac에만 있고 이동/이름 변경 후에는 새 경로의 이력으로 시작한다.
- 주석: 문서 끝 주석부터 제공한다. 본문 참조는 [1], 설명은 끝의 [1] 설명 형태로 편집하고 Markdown 저장은 `[^1]`/`[^1]: 설명`을 사용한다. 삽입/목록/이동/수정/삭제 및 Undo를 제공한다. 참조 번호는 재정렬하지 않는 안정 ID다. 설명은 한 문단(입력 개행은 공백)이다. 복잡한 다중 문단 Markdown 각주 및 페이지 하단 각주는 범위 밖이다.
- docx/hwpx 내보내기: 표시된 참조와 문서 끝 설명을 일반 텍스트로 보존한다. Word/HWP 고유 각주 객체는 이번 범위에 포함하지 않는다. txt 문서는 주석 삽입을 안내하고 비활성화한다.

## 인수 기준
보기 변경 후 Markdown 직렬화 동일. 저장본 중복 제거·자동 저장 간격·100개 보관·잘못된 백업 복원 차단·복원 전 백업·Undo. 주석 삽입/수정/삭제/재열기에서 참조와 설명 보존, 코드 안 표기 오인 없음, 내보내기에서 주석 텍스트 보존. 전체 회귀 테스트 및 빌드.

## 검토한 대안과 트레이드오프
배경을 문서 속성에 저장하면 내보내기가 오염되어 제외. 시스템 버전 복원만 의존하면 파일 시스템별 차이와 사용자 발견성이 있어 앱 목록을 선택. 전체 프로젝트 백업은 이미지·대용량 정책이 달라 후속 검토. 페이지 각주는 페이지 분할/내보내기 계약이 커서 문서 끝 주석부터 도입한다.
