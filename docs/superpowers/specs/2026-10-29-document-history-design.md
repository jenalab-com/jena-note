# 원고 버전 이력 설계

## 목적과 범위
기존 백업을 작가용 이력관리로 확장한다. 자동 저장 시점, 이름 붙인 버전, 현재 원고와의 줄/문단 단위 비교, 복원을 지원한다. 브랜치·자동 병합·Word의 변경 수락/거절은 제외한다.

## 저장 구조
내용은 SHA-256 객체로 한 번만 저장하고, 이력 메타데이터는 UUID·이전 이력 ID·시각·버전 이름·내용 해시를 가진다. 기존 데이터 포함 JSON은 읽기 호환한다. 객체를 먼저 원자적으로 저장하고 메타데이터를 나중에 저장한다. 손상된 객체는 오류로 표시하며 조용히 이력을 삭제하지 않는다.

문서는 별도 UUID와 macOS 파일 북마크로 식별한다. 경로가 바뀌면 북마크를 통해 기존 UUID를 찾는다. 다른 볼륨으로 복사하거나 북마크로 추적할 수 없는 이동은 새로운 이력이 될 수 있다. 기존 경로 해시 폴더는 최초 접근 때 UUID 폴더로 옮긴다. 경로 및 북마크 목록은 앱 로컬에 보관한다.

## 보관 정책
자동 이력은 최소 5분, 일반 저장은 내용 변경 시 기록한다. 이름 붙인 버전은 내용이 같아도 별도 시점으로 기록하고 자동 정리에서 제외한다. 이름 없는 시점은 최신 100개 유지한다. 부모 ID는 정리된 시점을 가리킬 수 있다. 내용 객체의 가비지 수집은 이번 범위에서 제외한다.

## 화면과 복원
기존 백업 창을 버전 이력 창으로 확장한다. 날짜·이름 목록, 버전 원문/현재와 비교 전환, 버전 남기기, 복원을 제공한다. 비교의 '-'는 선택 버전에만 있는 줄, '+'는 현재 원고에만 있는 줄이다. 큰 원고는 비교 비용 제한을 두고 원문 보기를 안내한다.
복원 전에 현재 미저장 원고를 보존하고 복원 자체도 새 시점으로 기록한다. 기록 실패 시 본문을 바꾸지 않는다. Undo와 수동 저장 경로는 유지한다. 이력은 로컬 텍스트 전용이며 외부 이미지 파일은 포함하지 않는다.

## 검증
중복 객체, 이름 붙인 버전 보호, 부모 연결, 기존 JSON 호환, 이동 추적, 복원 이력, 비교 방향 및 빈 원고를 검증한다. 기존 백업/저장 테스트를 함께 실행한다.

## 비교 화면 개선 (실사용 피드백 반영)
단일 텍스트 비교를 좌우 비교로 변경한다. 왼쪽은 날짜·이름으로 식별하는 선택 버전, 오른쪽은 미저장 내용을 포함한 현재 원고다. 각 열은 원본 줄 번호를 표시하며 수정(~, 주황), 추가(+, 초록), 삭제(−, 빨강)를 구분한다. 없는 쪽에는 빈 행을 두어 위치를 맞춘다. 수정·추가·삭제 줄 수를 표시하고 첫 변경 위치로 이동하며 이전/다음 변경 탐색을 제공한다. 세로 스크롤을 동기화하고 긴 줄은 가로 스크롤로 읽는다. 비교 내용은 선택 변경 또는 새로고침 시 갱신한다.
