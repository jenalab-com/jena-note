# Foundation Models 초기 파악 구현 계획

1. 설계 검토/ADR 기록: 2,400바이트 조각, local/excerpt 출처, 비지원 환경과 재시도 정책.
2. 로컬 요약 어댑터: OS/모델 가용성, 새 세션, 직렬 추론, 취소/시간 제한, 발췌 대체.
3. 인덱스 v2: 생성 경계에서 provider 제거, 출처와 상태 저장, 캐시/가용성 전환/명시 재시도.
4. 화면: 로컬 준비 안내, 요약/발췌 개수와 이유 표시. 탐색/답변 CLI 경로 보존.
5. 검증: 순수 로직·저장소·프로세스 통합 테스트, 실제 Foundation Models 한국어 실행, 전체 회귀/빌드 및 실행 기록.

구현 전에 설계 문서를 작성했다. 검증 중 발견한 수정은 개발 로그에 기록한다.
