# 구현 계획: 작품 인덱스와 자동 탐색

설계: ../specs/2026-10-28-work-index-design.md

1. 인덱스 모델: 안전한 원문 분할·해시·미래 화 제한·검색·목차·발췌.
2. 작품 공유 저장소: 백그라운드 스캔, AI 요약, 원자 저장, 증분 재사용, 진행·오류·중복 요청 처리.
3. 탐색 실행기: 제한된 JSON 대화, 검색/읽기, 예산 내 최종 payload, 취소·사용량.
4. 문서 열기/저장과 연결, 상태바·AI 패널 진행 표시, 자동 모드 자료 화면.
5. 요청 흐름에 연결. 기존 수동 요약은 보존, 일반 메모 경로는 유지.
6. 의미 있는 단위·통합 테스트와 swift test/release build. 결과와 남은 실사용 검증을 개발 로그에 기록.

사용자 승인: 설계·구현 문서 작성 후 구현 진행 요청(2026-10-28). 구현과 테스트까지 진행하며 릴리스·푸시는 별도 범위.

## 구현 기록
1~6 구현 및 자동 검증 완료. 추가 파일은 AIWorkIndex/AIWorkIndexStore/AIWorkRetrieval/AIWorkIndexView. 앱 모델이 직접 JSON 검색 요청을 반환하고 앱이 실행하므로 CLI별 별도 도구 프로토콜은 필요하지 않다. 기존 요약 파일은 보존하지만 자동 인덱스에는 혼합하지 않는다. 실제 유료 CLI 응답 품질과 대규모 작품 속도 검증은 남아 있다. 검증 결과: docs/devlog/2026-10-28-work-index.md.
